# iBM Lab Agent 0.4.1 完成书：路线编辑与 Agent 产物闭环

> 执行对象：接手实现的 Agent
> 前置条件：0.4.0 的三组件、Ketcher、事实核验和锁定基线全部通过

## 1. 版本目标

让用户在工作台直接创建和维护未锁定路线，并让实验计划、精读报告和 PPT 使用同一套“二次点击请求 Agent—等待登记—另存为本地”闭环。任何产物都不由按钮同步伪生成，UI 状态必须来自持久化任务记录。

## 2. 必须交付

### WP1 路线和步骤 CRUD

- 工作台支持新建路线，至少录入路线名称和目标化合物；目标支持选择既有实体或填写名称/CAS/SMILES。
- 未锁定版本支持添加、编辑、排序和删除步骤；删除必须二次确认。
- 步骤表单覆盖反应物、产物、试剂、催化剂、溶剂、用量/当量、温度、时间、气氛、浓度、后处理、纯化、监测、收率、注意事项、结构/CAS 和证据定位。
- 排序或删除后自动重编号并刷新路线图、事实绑定和产物过期状态；禁止留下悬空 stepId。
- Agent 与人工创建路线默认 `locked=false`；Agent 可修改所有未锁定版本。锁定版本必须复制为新版本后再改。

### WP2 实验计划模板

- 模板管理第三类完整支持新建、编辑、复制、归档、版本历史和版本快照。
- 模板字段至少包括名称、适用场景、章节顺序、必填字段、安全段、试剂表、操作格式、表征/质控和备注。
- 生成请求必须选择或解析实际模板；禁止在服务端硬编码永远使用 `experiment-plan-default`。
- 产物登记保存模板 id/version 和不可变快照；模板后续更新不得改变旧产物。

### WP3 三类产物统一状态机

适用于 `experiment-plan-docx`、`reading-report-docx`、`literature-pptx`：

1. `idle`：灰色未生成。
2. `confirm-send`：第一次点击，仅显示将发送给 Agent 的摘要，不创建任务；切页、切对象或超时后恢复 `idle`。
3. `requested`：第二次点击创建一次幂等请求并向 Agent 发送消息。
4. `generating`：Agent 已领取/执行；同对象同类型禁止重复任务。
5. `ready`：Agent 登记经过完整性校验的本地文件；按钮亮起。
6. `stale`：输入路线、步骤、模板或文献版本变化；旧文件仍保留并提示可能过期。
7. `failed`：保留错误摘要和请求参数，允许明确重试。

- `ready` 后点击执行桌面“另存为”：实验计划和精读报告为 DOCX，PPT 为 PPTX。
- 现有已登记文件升级后直接进入 `ready`，不要求重新生成。
- 实验计划始终 `requiresReview=true`，不得触发实验执行。

## 3. 建议数据与接口

- 新增统一 `artifactRequest`：`id/artifactKind/projectId/routeId/stepId/reportId/templateSnapshot/inputRevision/requestState/requestedAt/startedAt/completedAt/filePath/fileSha256/error`。
- 唯一键至少覆盖对象、产物类型和有效输入版本；`requested/generating` 状态创建重复请求必须返回既有任务。
- 接口：`artifact_request_prepare/create/get/retry/register/save_as`。`prepare` 只返回请求摘要；`create` 才产生 Agent 消息。
- 文件登记校验扩展名、文件签名、大小和 SHA256；不能只因存在路径就把按钮点亮。
- 路线/步骤影响计划的字段更新后统一调用失效标记服务。

## 4. 自动化与人工验收

- 状态机逐边测试，特别验证第一次点击零请求、第二次点击恰好一次请求、重复点击幂等、失败可重试和切换对象取消确认态。
- 模板 CRUD、版本快照不变、旧产物兼容测试。
- 路线创建、全字段编辑、排序、删除确认、锁定写保护和悬空引用测试。
- Windows 桌面测试三类文件“另存为”，取消保存不得改变 `ready`，保存失败错误可见。
- 人工验收分别生成一个实验计划 DOCX、一个精读 DOCX 和一个 PPTX，关闭并重启桌面后状态仍正确。

## 5. 明确不包含

- 完整可视化结构编辑器和自由拖拽路线拓扑。
- NMR/绘图登记的最终迁移与发布性能专项（0.4.2）。

## 6. 完成定义

路线 CRUD 可由普通用户完成；三类产物共享同一持久化状态机且二次点击只产生一次 Agent 请求；模板版本可追溯；所有文件均能在 Windows 另存为；升级、重启、失败重试和输入变更场景全部通过。
