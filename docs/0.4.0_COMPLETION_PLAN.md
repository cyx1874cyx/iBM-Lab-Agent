# iBM Lab Agent 0.4.0 完成书：结构图工作台与事实核验基线

> 执行对象：接手实现的 Agent
> 前置版本：0.3.x 只作为迁移输入，不继续扩展旧工作台
> 发布性质：P0 基线版本；本书所有验收项通过前不得发布 0.4.0

## 1. 版本目标

把合成路线工作台收敛为可用的三段式图形界面，修复 Ketcher 离线渲染，建立名称/CAS/结构双源核验和以原文截图为依据的人工审核门禁。0.4.0 只解决“路线是否看得清、结构是否可信、事实是否审核完成”，不在本版实现完整产物生成工作流和自由拖拽结构编辑器。

## 2. 必须交付

### WP1 Ketcher 打包与渲染

- 修复 `client/assets/ketcher-standalone/index.html` 与哈希资源不一致的问题；禁止手改哈希文件名后遗漏入口更新。
- `prepare-runtime.ps1` 在删除旧资源前验证源码 Ketcher 的全部 `src/href` 引用。
- 缩略图缓存键包含规范化结构、宽高、主题和渲染协议版本。
- ready、载入、渲染、导出分别设置超时和可重试错误；失败不得无限显示“渲染中”。
- 同一页面连续渲染至少十个结构；某一项失败不得阻塞后续队列。
- 安装包断网环境中完成 ready、SMILES 载入和 PNG/SVG 导出。

### WP2 三组件工作台

- 最大外框内部只保留三个主要全宽组件：合成总览、单步详情、事实核验。
- 顶部仅保留路线/版本选择、锁定、新建路线、添加步骤和“更多”；Evidence 数量、提取能力、置信度、Tier 等不常驻展示。
- 组件一用 Ketcher 分子图、名称、CAS、条件摘要和箭头组合完整路线，支持稳定折行或横向滚动；禁止以文字步骤卡作为最终实现。
- 点击路线步骤后只用边框/底色高亮，并同步切换组件二和组件三。
- 组件二固定为反应物 → 条件/注意事项 → 产物三栏。中栏必须覆盖试剂、催化剂、溶剂、温度、时间、气氛、浓度、后处理、纯化和监测，不再追加旧式长条件表。
- 分析与决策只显示一段不超过 50 个中文字符的化学性质难点说明。

### WP3 化合物身份与双源核验

- 最终结构记录持久化 `name/casNumber/smiles/inchiKey/source/verification`。
- PubChem 与 CACTUS 并行或独立查询，完整记录两源结果；四态为 `dual-confirmed/single-source/conflict/unresolved`。
- 冲突和未命中不得自动写入；单源结果必须由用户确认；人工 Ketcher 结构优先且不被外部结果覆盖。
- 删除绕过双源核验的 PubChem 单源自动写入入口，或将其降级为仅展示候选。
- CAS 必须通过格式校验并携带来源；未知时显示“CAS 待确认”。

### WP4 截图事实核验与路线锁定

- 组件三左侧为当前步骤格式化事实单元，右侧只显示当前选中事实对应的原文/SI 截图；支持页码/bbox 定位、放大和打开原 PDF。
- 每项具有“确认、修正、无法确认”。修正同时保存 `originalExtract` 和 `userCorrection`。
- 无 PDF/SI、页码或截图失败时明确显示缺失原因，并禁止把该项计为“截图核验完成”。
- 用户完成本轮全部事实后才能提交；新增批次实体记录轮次、项目/路线/步骤、事实集合、提交人、提交时间和状态。
- Agent 只处理无法确认、缺失、冲突和需重算项；不得覆盖人工确认项。Agent 新增内容进入下一轮 `pending`。
- 路线锁定必须同时检查：所有步骤无待审事实、所有必需截图审核有效、没有运行中的审核批次。只有用户可锁定；锁定后所有写接口服务端拒绝。

## 3. 建议数据与接口

- 扩展 `stepStructure`：保存 CAS、InChIKey 和完整双源 provenance，不能只保存在临时候选面板。
- 新增 `synthesisReviewBatch`：`id/routeId/stepId/round/status/itemIds/uncertainItemIds/createdAt/completedAt`。
- 新增远程接口：`synth_review_batch_create/get/complete`、`synth_review_uncertain_apply`。
- `synth_route_lock` 返回结构化阻断原因和需定位的步骤/事实 ID。
- 旧 Evidence 自动补 `reviewRound=1`；不得把每次单项点击都误当作新审核轮次。

## 4. 自动化与人工验收

- 单元测试：双源四态、CAS 校验、缓存键、状态迁移、批次完整性。
- 集成测试：未锁定版本可写、锁定后所有写入口拒绝、人工确认不可覆盖、无截图不能完成、批量更新只影响不确定项。
- 浏览器测试：三组件数量与顺序、步骤联动、纠正值保存、十结构连续渲染、超时重试。
- 打包测试：源码与资源快照 Ketcher 引用全部存在，`verify-package -WebSmokeTest` 通过，安装后断网渲染通过。
- 人工验收至少使用一条四步路线、正文 PDF 和 SI，完整走完两轮事实核验并锁定。

## 5. 明确不包含

- 实验计划、精读报告和 PPT 的统一 Agent 产物状态机（0.4.1）。
- 完整步骤 CRUD 和复杂路线人工编辑（0.4.1）。
- 自由拖拽、多步拓扑编辑和完整内嵌 Ketcher 编辑器（后续 0.5.x 候选）。

## 6. 完成定义

以下条件缺一不可：工作台视觉验收通过；浏览器级 Ketcher 测试通过；事实审核与锁定门禁通过；所有结构显示名称/CAS；源码测试、回归、打包 Web 冒烟和干净 Windows 安装验收通过；发布包由干净提交构建并记录 SHA256。
