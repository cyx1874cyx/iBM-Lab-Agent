## 4. 关键架构约定(接手 Agent 快速上手)

- **形态**:DeepSeek Harness 插件(dsh-lab-agent,不修改 Harness 核心)+ Tauri 桌面壳
  (bundled node/dsh/plugin/python 一次性入包,离线开箱即用)+ Edge 浏览器扩展
  (Native Messaging bridge 捕获 PDF/SI)
- **前端**:`client/index.js` 单文件 React 注入(无重型 bundler),构建走
  `scripts/build-client.mjs`;新 UI 资源(Ketcher)随包托管经 webServer 同源服务
- **服务注册**:插件服务在 `cordis.patch.yml` 注册;新增 service 须同步
  `package.json` exports 子路径 + client descriptors(`lib/remote.js` markRemote 登记)
- **一致性检查**:`npm run check:preset-exports`(preset 挂载 ⊆ exports)与全量
  `npm test`、回归 `npm run regression` 是改动后必跑
- **打包流程/判活/避坑**:一律读 `desktop/docs/packaging-pitfalls.md`(§0-13,
  含 tauri-build patch、Remove-TreeFast 慢分支判活、增量 18m vs 全量 45m 判断、
  verify-package 三层验证、双实例并发坑等),不要凭直觉另起炉灶
