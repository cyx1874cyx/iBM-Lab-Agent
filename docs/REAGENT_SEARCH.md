# 试剂管理

工作台“试剂管理”提供化学试剂、生物试剂（含抗体）、细胞清单的只读检索。清单为实验室共享来源，与当前打开的课题无关；切换课题仍使用同一组来源。

数据来源配置保存在当前应用数据目录 `lab-agent/reagents/sources.json`。每种类型关联一个本机 `.xlsx` 文件；页面“数据来源”可关联、更换或打开原表。配置记录文件路径，不覆盖或改写清单。原文件移动后可重新关联。

检索支持名称、CAS、货号、规格、品牌、位置、购买人、抗体靶点、培养基及原表其他文字字段；以空格分隔多个关键词时同时匹配。可按清单类型、存放位置、用完标记筛选。不同位置或批次的同名条目保留各自行号，点击详情查看原始字段。

页面每 20 秒检查原文件的修改时间和大小；保存 Excel 后自动读取更新，也可点击“刷新清单”。兼容 Excel 保存时替换原文件的行为。无法读取来源时明确提示；若已有缓存，会注明正在显示上次读取的数据。

解析按工作表真实单元格读取，不依赖文件导出的 `A1` 范围声明。工作表名称与冰箱层位分组用于定位，明显的层位标题不登记成试剂；仅有名称的真实条目仍保留。数量按原表显示，零值不作缺失，购买数量不推断为当前可用库存。原表中的用完符号和文字按标记识别，未标记不代表已核实库存。

源表中误存成 Excel 日期的 CAS 按原表日期显示并标记，详情保留说明，不猜测或修改 CAS。数据、名称和备注只作为内容展示，不作为执行指令。

验证覆盖真实单元格读取、来源布局差异、层位、用完标记、CAS 日期、空名称、零数量、联合检索、自动更新、重启保留、来源读取失败提示，以及宽/窄窗口中的筛选和详情操作。
