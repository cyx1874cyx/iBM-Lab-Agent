# iBM Lab 文献阅读与原文批注需求

**产品需求草案 · 2026-11-04 · 文献阅读插件**

## 1. 用户目标与范围

读者打开一篇论文，可能只有五分钟，想弄懂作者研究了什么、做了哪些工作、得到了什么结果；也可能正在准备汇报，需要逐图检查实验条件。同一篇论文应当支持两条路径，读者可随时从概览进入原文，也可直接打开原文开始阅读。

| 需求层级 | 范围 |
|---|---|
| 用户已明确的核心需求 | 使用精读模板快速读懂文献并生成 PPT；阅读原文时框选、提交问题、连续追问；系统提炼答案并自动保存到原处；图钉单击查看、双击修改。 |
| 建议的首版默认行为 | 首次回答自动落钉，追问后由用户决定是否更新短答；支持直接记笔记、查看依据、从目录回到批注；生成回答期间可以继续阅读。 |
| 可后续增加 | 将选中的批注加入 PPT、搜索批注、合并显示位置接近的图钉。首版完成条件见第 8 节。 |

## 2. 模板速读与 PPT

1. **进入。** 在文献条目提供「快速读懂」与「阅读原文」。速读默认使用用户当前的精读模板，生成前可切换模板。直接阅读原文无需先生成概览。
2. **阅读。** 按所选模板展示概览。通用默认模板至少回答三个问题：作者想解决什么问题，具体怎么做，观察到了什么。用户自定义章节及生成要求优先。
3. **核对。** 有可靠定位的结论旁显示「第几页」或「图几」，点击后打开对应原文，返回时保留概览阅读位置。无法可靠定位时仅展示已有依据。
4. **汇报。** 在概览页点击「生成 PPT」，沿用已有 PPT 模板选择与生成流程。输入使用当前文献和选中的概览版本；有明确来源的图表或结论保留出处。用户可以只读概览，也可以直接完成汇报制作。
5. **保留历史。** 更改默认模板只影响后续生成。重新生成概览或 PPT 时保留已有历史任务快照和原文批注。

## 3. 原文批注的完整操作

| 步骤 | 读者操作 | 产品响应 |
|---|---|---|
| 选择对象 | 选中一段文字，或框住图表、公式、扫描页中的局部区域 | 在选区附近显示「提问」「记一笔」。输入框保留所选文字或区域缩略图，便于核对指代。 |
| 提交 | 写下问题，点击「提交」 | 立即保存问题和选区，原处出现待回答图钉。用户可以翻页、收起卡片或继续提交其他位置的问题。 |
| 接收答案 | 无需额外操作 | 回答成功后，系统提炼短答并保存到提交时的批注，图钉变为已回答。保持读者当前页与滚动位置。 |
| 回看 | 单击图钉 | 打开批注卡，高亮原选区。优先显示原问题、当前短答及依据，可展开完整问答。点击卡片外部可收起。 |
| 追问 | 在卡片内点击「追问」 | 继续使用同一文献、选区及本条历史对话；新一轮问答归入同一图钉。用户可采用新的精炼摘要。 |
| 修改 | 双击图钉，或点击卡内「编辑」 | 直接编辑当前短答。保存后显示修改后的正文，取消则恢复编辑前内容。原始问题及历次回答可回看。 |
| 自己记录 | 选择「记一笔」并保存 | 原处生成个人批注，正文为用户输入，不触发模型回答。 |

**示例。** 读者框住图 3 的误差线，问“这里是 SD 还是 SEM？”假设图注仅注明样本量，卡片短答可写为“图 3 图注仅注明 n = 3，未说明误差线类型。”读者继续问“方法部分有没有说明？”若在方法章节找到定义，新回答给出该处依据；读者点「更新批注摘要」后，图 3 的原图钉展示更新后的结论。

## 4. 短答、追问与编辑规则

- **首答。** 针对所问内容优先给出结论，通常一至三句；单位、实验条件、样本量和适用范围按问题需要保留。正文证据不足时，指出查到了什么、哪一点仍未说明。
- **证据。** 答案可引用选区、图注或本文其他位置。界面区分“提问位置”和“答案依据”，依据可定位时支持点击跳转。图像无法辨认时提示放大或重新框选。
- **两层内容。** 卡片默认显示便于下次阅读的短答，展开后显示完整问答。修改卡片正文后标记“已手动编辑”，保留模型原答，以便读者分辨来源。
- **追问后的摘要。** 建议先展示更新草稿与当前正文，点击「采用」才替换。若生成期间用户已经修改正文，保留手动版本，仍允许查看和采用草稿。
- **独立问题。** 在已有卡片中追问延续当前讨论；重新框选并提问则新建批注，即使两个问题指向同一张图，也分别保存。

## 5. 图钉、定位与找回

- 图钉靠近选区边缘，避开正文、数据点和图例；选区仅在选中或回看时突出显示。相邻图钉均应可点选，用户可临时隐藏全部图钉。
- 批注跟随当前文献、文件版本、页码及页内选区。缩放、旋转、改变窗口大小和重开同一 PDF 后，应仍对应同一处文字或图像。
- 当前文献提供批注目录，按页排列，展示页码、问题或笔记首行。点击后回到对应页、突出选区并打开卡片。删除批注时应明确删除范围，并提供撤销或确认。
- PDF 被替换且无法确认原位置时，目录保留问题、短答、对话及原选区摘录，标注“位置待重新绑定”，允许重新选区。不同文献的批注隔离。

## 6. 生成状态与异常恢复

| 场景 | 用户应看到的结果 |
|---|---|
| 同时提交多个问题，回答先后顺序变化 | 每条回答写回自己的批注。切换文献后，结果仍归入原文献。 |
| 生成中翻页或关闭阅读页 | 已提交的问题与定位保留。重新打开能看到已答、生成中或可重试状态。 |
| 请求失败、超时或应用退出导致中断 | 原图钉显示「重试」，保留已提交问题和已有对话。重试沿用同一条批注。 |
| 用户连续点击提交，或已删除批注后旧回答才返回 | 一次提交只创建一条记录；已删除的图钉不会因迟到的答案再次出现。 |
| 生成 PPT 失败 | 允许在当前文献重试，概览、历史成果和批注仍可打开。 |

## 7. 数据归属与插件边界

文献阅读插件负责原文定位、批注正文、对话关联及 PPT 输入。每条批注至少能找回所属文献、文件版本、选区、问题、当前正文、问答历史、生成状态与最后修改时间。个人笔记与助手解读应可区分。此流程可在仅装配文献阅读插件时独立使用。已有研究数据、配置及历史任务快照继续可读。

后续若支持向 PPT 加入批注，由用户勾选具体条目。预览中应能区分论文结论和读者补充，并显示可用的原文页码或图号。

## 8. 首版验收场景

| 编号 | 操作 | 通过条件 |
|---|---|---|
| A01 | 从一篇文献选择模板生成概览，再生成 PPT | 概览符合所选模板，PPT 对应当前文献及概览版本；不要求用户先创建任何批注。 |
| A02 | 从概览中有页码依据的结论进入原文，再返回 | 进入正确页；返回后仍能接着读原来的概览段落。 |
| A03 | 分别对可选文字和扫描页上的一张图提问 | 两种选区都能提交并自动落钉，首答成功后可直接查看短答，全程无需再次确认保存。 |
| A04 | 向两个不同区域连续提交问题，然后翻页 | 回答各归其位，当前阅读页保持不动。 |
| A05 | 单击图钉、追问两次、采用摘要，再双击修改 | 一枚图钉保留三轮问答；卡片展示手动保存后的内容，重新打开仍然一致。 |
| A06 | 针对原文未说明的问题提问 | 短答明确指出缺失信息，不虚构数值、结论或页码。 |
| A07 | 保存一条个人笔记，关闭文献，重新打开并从目录定位 | 可看到原笔记与对应选区；缩放或旋转页面后两者仍匹配。 |
| A08 | 中断一次回答后重试，并在已有首次短答的追问中手动编辑 | 重试不产生重复图钉；迟到的模型结果不会覆盖用户已保存的文字。 |
| A09 | 在仅启用文献阅读子插件的环境中打开已有文献 | 原有任务快照可读；速读、批注、PPT 三条操作路径均可从文献条目进入。 |
