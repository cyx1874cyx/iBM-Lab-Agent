# iBM Lab 知识库接入

复用 DSH-RAG 0.2.1 的检索核心（来源与许可证见 vendor/dsh-rag），使用当前科研工作台界面和科研助手，无需运行原插件的独立网页服务。

## 使用

打开 `.ibmproject`，进入「RAG 知识库」。默认仅选择当前课题。课题的 `literature/` 自动纳入索引；上传或拖入的 PDF、DOCX、PPTX、Markdown、TXT 存在 `knowledge/materials/`，单个上传文件最多 25 MB。直接放入文件夹的文件按原插件 100 MB 上限处理。PDF 必须有可提取文字，当前不含扫描件 OCR。

「关联已有知识库」选择旧插件包含 `config.json` 与 `catalogs/` 的索引文件夹。共享库默认不勾选，原文件与索引均只读；若原插件更新索引，下次检索会自动重新加载。原文件移动后应先在原插件更新索引。共享库的关联配置保存在本机 `lab-agent/knowledge/libraries.json`。

搜索结果显示引用编号、资料类型（来源提供时）、年份、原文片段和页码/段落/行号。PDF「预览原文」在软件内打开并请求定位对应页；「定位文件」在文件资源管理器中选中原文件。其他格式显示检索原文片段并支持定位文件。

页面主体是专用知识库问答。直接在底部输入问题并发送；`agent/pre-step` 在每轮用户消息进入模型前强制检索，将证据记录为折叠通知，使用当前配置模型流式回答。同一问答中可连续追问；「新建问答」开始独立上下文。除知识库检索外，此模式可只读访问软件内其他科研模块及项目资料，并保留用户命令驱动的精读归档能力。知识库未命中时仍可查询已有应用记录，回答必须区分知识库证据和实际读取的记录，不能编造内容。

`lab_research_read` 提供课题概况与记忆、检索和精读/PPT、核磁结果、绘图、合成路线/化学记录、试剂清单、模板、申报/润色草稿、历史及项目文件的只读查询。默认当前课题，可显式指定其他已加载课题。记录与文件通过 `nextOffset` 分页；按 `id` 读取完整记录。PDF、DOCX、PPTX 和文本在内存中解析，单文件最多 32 MB，不生成转换产物或触发任务；扫描 PDF 若没有可提取文字会如实提示。试剂信息来自现有关联清单，不改写 Excel 或来源配置。模板读取不会补种或升级版本。

工具执行时再次校验权限，不能通过猜测隐藏工具名称调用命令、修改/删除记录或启动分析；`read` / `read_image` 仅可读取当前课题文件夹或已登记的科研文件。已有精读归档操作仍需用户明确命令，其余模块保持只读。普通科研会话的权限不变。

## 从问答加入精读

可直接说：“把刚才推荐的 G061、G062、G015 加入精读，新建一个‘MRI 与血栓异质性’文件夹。”助手调用 `lab_knowledge_add_to_reading`，使用所选知识库完整索引查找正文及 SI，按 DOI/稳定文献编号关联，不受当前仅查看笔记的筛选限制。此前轮次的来源可用 `T1:S3` 精确指定；明确编号不在当前命中片段中时仍可查完整索引，不能用别篇替代。

只有用户明确下令或紧接上次请求确认时才执行；推荐和讨论不会自动写入。只操作当前课题精读条目与其项目文件夹，正文及 SI 复制归档，共享源文件和索引不变。同名精读文件夹及已有文献条目复用，不覆盖现有正文和已完成报告；没有正文则创建待补 PDF 的条目，不把既有知识库笔记冒充新精读报告。每次最多 20 篇，总文件大小最多 256 MB；错误编号或过期源文件在写入前报错，部分归档失败如实返回。面板通过现有项目变更通知刷新。

「知识库设置」展开资料管理、检索范围和筛选条件，选择按会话保存到项目 `.ibm-rag/chat-sessions.json`。普通科研会话不受此模式影响。最近 30 轮检索来源与轮次一起保存；回答中的 `[S1](#ibm-rag-轮次-S1)` 等链接打开对应轮次的「回答来源」，可继续预览 PDF 原文或定位原文件。其他科研会话仍可用 `lab_knowledge_list` / `lab_knowledge_search` 工具按需检索。资料类型和年份筛选使用索引文献元数据；没有相应元数据的普通资料只在未设置该筛选时返回。

## 索引与迁移

每个项目的 `.ibm-rag/index/` 保存原版目录格式；`.ibm-rag/project-root.json` 用于整个项目文件夹移动后的路径重定位。打开课题知识库时首次自动同步，文件变更去抖后同步，60 秒补偿检查；界面每 5 秒读取进度，也可手动「更新课题索引」。索引是可重建缓存，不写入 `.ibmproject` 的业务数据库，不修改精读登记、文件名或正文。请移动整个项目文件夹。

多个知识库检索按各库候选排名交错合并，不直接比较不同语料的 BM25 分数。默认使用本地 BM25 与原插件医学词扩展；本次没有启用云端嵌入、重排或增加云服务凭据。

## 开发与验证

`node scripts/build-rag.mjs` 从带版本的本地源文件构建 `lib/rag/`，包含纯 JS PDF 文本解析与几何运算，不依赖系统原生 canvas。`scripts/start-workbench.ps1` 会先构建检索核心再启动开发版。

验证：`node --test tests/integration/knowledge.test.mjs`；`node --test tests/browser/knowledge.test.mjs`。覆盖 PDF/DOCX 入库、增量重命名/删除、共享库不变、项目隔离、搬迁后来源定位，以及界面检索、筛选、问答交接、整区拖拽与窄屏布局。
