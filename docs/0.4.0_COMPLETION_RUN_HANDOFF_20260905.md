## 7. 关键设计决定（勿在未读需求书前推翻）

1. 轮次（reviewRound）只由 Agent 回写开启；人工确认/修正/无法确认**不**推进轮次
   （需求书 96-104 行 + AC-EV-04；修正值 userCorrection 与 originalExtract 双保留）。
2. 批次状态机 pending（待 Agent）→ applied（Agent 已回写）→ completed（关闭）；
   **锁定只阻塞 pending 批次**，applied 后由"待审证据门禁"接管（Agent 新内容以
   pending 进入下一轮，人工确认后才满足锁定条件①）。
3. 锁定三条件 = ①无 pending 证据 ②无 pending 批次 ③confirmed 证据必须有
   bundle/document+page（截图核验依据）。阻断以结构化 blockers 返回 UI。
4. UI 禁止对无截图依据项点"确认"（提示修正/无法确认），服务端 lock 兜底拒绝
   confirmed-without-shot。
5. 双源只查不写；登记必须人工点击并持久化 casNumber/inchiKey/verification。
6. Ketcher 缓存键含协议版本，shell 协议变更时递增 `KETCHER_RENDER_PROTOCOL`。
