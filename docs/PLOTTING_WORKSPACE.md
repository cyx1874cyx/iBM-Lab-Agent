# 科研绘图工作台

## 跨条目多图排版

标题区「多面板排版」现在创建独立的组合版面，可多选当前已经成图的所有来源：任意图型的 Origin 保存图/初稿、PNG/JPEG/WebP/TIFF/BMP/GIF 图片条目，以及已有组合版面。没有成图的数据条目需先生成初稿。入口不再限制为「一个条目有多个 Y 系列」。

版面使用毫米尺寸，左侧为素材与图层，中间为整页画布，右侧为对象/页面设置。支持拖动、多选/框选、四角缩放、锁比例、六向对齐、选区/页面/主选参照、水平/垂直等距与指定间距、等宽/等高、自动网格、自由成组及行/列/网格约束。布局组成员尺寸变化后重排；固定和锁定对象不随重排移动，成组对象作为整体对齐。网格、标尺、参考线和吸附仅辅助编辑，不出现在成图中。

可调整单个面板的裁剪、旋转、翻转和透明度，也可添加文字、箭头、矩形和比例尺。比例尺文字由用户填写，软件不会从图片猜测真实物理尺度。自动序号默认放在图片外上方，初始排版间距为 6 mm；可改到图内并调整字号及边距。

选入来源时复制完整 PNG、预览及可用矢量 PDF，记录来源条目和哈希，后续来源编辑/删除不会改变已保存版面。编辑操作在浏览器内完成，不调用 Origin 重绘。保存使用版面文档和对应素材快照生成 PNG/PDF/TIFF，提供 150/300/600 dpi；PDF 保留可用的 Origin 矢量内容，翻转或透明度处理的面板以图片合成。导出前会先保存当前修改；失败保留上次成功版本。版面记录可重新打开继续修改，保留最近 20 个历史版本，支持直接恢复历史原图。

组合版面作为独立条目归档，提供「下载 PNG / 下载 PDF / 修改排版」；TIFF 在编辑器中下载。修改窗口关闭前提醒未保存更改，异常关闭保留本地文档草稿。保存错误保留在编辑器内，成功提示自动消失。

## 导入图片条目

可直接拖入或选择 PNG、JPEG、WebP、TIFF、BMP、GIF 图片。支持批量导入，每个文件生成独立条目；每次最多 20 个文件，每个文件不超过 25 MB、图片不超过 4000 万像素。多帧图片明确提示只编辑第一帧。图片处理不连接 Origin，也不调用 AI。

图片条目显示缩略图、格式、尺寸和修改时间，提供「原始图片 / 下载图片 / 修改图片」。编辑器支持拖动裁剪框与四角、按像素设置裁剪范围、左右旋转 90°、水平/垂直翻转、撤销/重做和恢复原图。旋转后的水平/垂直翻转按屏幕方向解释。裁剪在原图上选择，完成后显示旋转与翻转结果。

预览在本地即时更新；保存时从不可变原文件应用完整配置，生成完整像素尺寸的 PNG。预览尺寸单独限为 2000 像素长边，避免大图拖动卡顿；导出不使用预览分辨率。原始格式和字节保留，EXIF 方向在编辑视图和输出中归正。保存失败保留上次版本，支持重试；关闭未保存编辑会提醒。重新打开继续应用已保存的裁剪/旋转配置。

## 导入数据并使用 Origin 绘图

在科研绘图模块点击「新建绘图」，或拖入一个 CSV、TSV、TXT、XLSX、XLS 文件（不超过 25 MB）。一个条目对应一个原始文件和一个选定的工作表。

1. 原始字节归档到课题目录 `科研绘图/<条目 ID>/原始数据/`。先读取 Excel 全部工作表名称，选择工作表和表头后预览数据；空首页及说明页不会阻断切换。第一行默认为表头，0 表示无表头。数据预览不依赖 Origin 或 AI。
2. 选择任意适用图型及 X/Y 数据列；AI 推荐为可选排序参考，等待推荐时也可跳过。框选数值列可不相邻，并可调整绘图顺序。箱线、条形图通过连续的派生列导入 Origin，原始文件及源列身份保持不变。
3. Origin 生成初稿，编辑器直接显示原生 PNG。参数先保存在设置区草稿，回车或离开设置区统一提交。预览更新期间可以继续修改、撤销或重做；后台合并待运行请求，过期结果不发布，旧图标为待更新，失败后可重试。保存使用最新配置及对应的完整 PNG/PDF/OPJU 产物。

条目左侧显示缩略图、名称、创建/绘制时间和状态；右侧保留原始数据、Origin 工程、修改图片三个入口。点击缩略图可打开图片预览并下载已保存版本的 PNG 和 PDF。保存失败保留上一版。所有生成版本保留在条目目录的 `版本/` 下，移除登记不删除这些文件。历史版本支持「恢复原图」（复用原产物，确认保存后切换正式版本）和「按旧配置重绘」（生成新草稿）。

支持折线图、点线图、散点图、柱状图、水平条形图、箱线图和直方图。数值列用于 Y，点线/散点图需要独立数值 X；箱线图将每个数值列作为一组，直方图只选择一个数值列。柱状图按原始行绘制，不自动合并重复类别或取均值。保留空值及行顺序，不自动平滑、拟合、删点、归一化、推断误差类型或显著性。日期当前作为标签列；不提供连续时间轴转换。超过十万行、256 列或两百万单元格需拆分。

默认单图使用 Arial、9 × 8 cm 图层、轴标题名义字号 36、刻度/图例 32 和 3 pt 线宽；允许用户调整。界面不自动宣称图形通过期刊/课题组标准验收，用户仍需检查遮挡、坐标范围、缺失值及科学口径。

## 实现与运行

### 2026-10-31 图型样式映射

参数输入先保存在设置区草稿中，数字不再逐字符提交。设置区内切换输入框或类别可连续填写多个参数；按回车或将焦点移出设置区时，校验并合并提交一次。未完成、越界或互相冲突的参数不会调用 Origin。提交后保留旧图片并标注待更新，参数与撤销/重做保持可用。

人工修改显示 Origin 原生 PNG。首次绘制、保留工程的增量编辑和最终保存统一使用 `plot_editor.series_commands`，逐源数据列设置样式；分组模板先切为独立编辑，避免其他系列覆盖自定义颜色。

| 图型 | 系列设置 |
|---|---|
| 折线 | 颜色、线宽、线型、不透明度、显示/隐藏 |
| 散点、点线 | 系列色、符号填充色/边框色、大小、形状、实心/空心、边框粗细、不透明度；点线另有线宽/线型 |
| 柱状、水平条形 | 填充色/边框色、边框粗细/线型、柱间距、不透明度、显示/隐藏 |
| 箱线 | 填充色/边框色、边框粗细/线型、箱宽、箱体不透明度、显示/隐藏 |
| 直方 | 填充色/边框色、边框粗细/线型、组距、不透明度、显示/隐藏 |

散点符号填充与边框分别使用 `-csf/-cse`；柱体及箱体使用 `-pfb/-pbc`。箱线模板的透明度位于 `Patterns.Above`，需关闭跟随根线条透明度，不能仅依赖通用 setter 返回成功。直方图组距变化会重建派生频数，创建时设置组距，清空恢复自动分箱；普通样式修改继续保留图与数据，不再次写组距。

`node scripts/migration/verify-origin-chart-styles.mjs` 在独立测试文件夹检查七类图的实际导出颜色、透明度、连续修改、图型专属设置及隐藏/恢复。可在命令后指定图型缩小回归范围；测试不替换用户项目。

- `lib/plot-workspace.js`：归档、AI 推荐、后台任务、版本提交和文件校验。
- `src/plot/workspace.js`：配置契约、图型目录及列角色验证。
- `scripts/runtime/plot_job.py`：只读数据解析及安装版 Origin MCP 调用；不运行上传的脚本。
- `client/src/components-plotting.js`：向导、预览、画布和条目。
- `plot_workspace_upload/recommend/render/discard` 为 Remote 接口；大文件和图片使用同源二进制端点。

运行端需要随包 Python（pandas/openpyxl/xlrd/Pillow/numpy/origin_mcp）及已安装授权的 Origin。先启动 Origin 并点击已有的「Origin MCP Bridge Start」。应用不通过截图模拟图、不重置 Origin 项目，也不自动安装或改动授权配置。每次绘制只使用唯一临时 Project Explorer 文件夹，完成后移除自己的文件夹，恢复此前活动目录和窗口。

已完成和历史条目继续使用现有存储域。工作流是绘图登记记录上的可选字段；现有记录不迁移、不清除。路径由工程文件管理器按原有机制随工程迁移。运行中任务在应用重启后标记为中断，原始文件和已确认版本保留。

## 本地实时编辑与 Origin 核对

初版生成后，编辑界面从已校验的数据副本加载完整数据，本地 SVG 立即重绘曲线、轴标题、图例和标注。属性调整、拖动和撤销不调用 Origin；历史版本恢复和 AI 对象配置修改也只更新配置。点击「交给 Origin 核对」才调用原生绘图，展示并排预览与结构核对记录。核对期间继续修改配置会使正式保存按钮失效，需重新核对。点击「确认一致并保存」复用同配置的已验证草稿文件，不再次调用 Origin。

自动检查覆盖能够读回的图层、系列数量、轴标题、手动范围、已设置的颜色和符号、文字位置；缺少原生读回证据时标为未验证。字体字形、排版、统计图口径和像素一致性仍需用户在并排预览中确认。本地直方图当前显示 10 个等宽区间，箱线图用线性插值四分位数；应核对 Origin 的默认统计定义。该预览不作发表结果，归档图片以 Origin 原生导出为准。

开发构建和客户端同步改为写临时文件后原子替换，避免热刷新读到未完成的注册文件。恢复模式不需要重置 Profile；开发版重建与重启后已验证工作台正常加载。

## 2026-10-30 流程调整

导入后，AI 先根据数据摘要推荐图样式；用户选择图型与列映射后，才开始生成初版。本地粗图和 Origin 初版共享同一份配置。AI 不可用时明确标注规则粗图，用户仍须选择，系统不会把规则推荐冒充 AI。支持的数值轴在生成时固定相同的范围和主刻度间隔；可手动调整。

本地画布完成设计后，点击「完成设计并生成 Origin」异步生成并归档 Origin 工程；条目缩略图和图片预览优先显示 Origin 原生 PNG。本地草图只作为操作辅助。原始数据与 Origin 工程保留独立入口。

条目上的「Agent 精修」为可选操作：Agent 根据本地配置和 Origin 位置读回，提出图例或图标题的受限位置微调；轴标题自动精修暂停，等待坐标语义和文字重叠检测得到验证。不执行模型生成的脚本，不修改数据、图型或坐标范围。候选只作为待核对草稿保存；用户可以比较本地预览、候选和原工程，确认后才替换正式工程并将原工程归入历史。位置分数仅供参考，不代表视觉质量。支持图像输入的模型且存在本地预览快照时，会附带本地目标图和 Origin 导出图辅助判断。直方图分箱、箱线图统计规则以及字体排版仍需并排核对。

点击「Agent 精修」会打开右侧科研助手中与该绘图条目绑定的对话，并在该对话中请求精修和报告结果。条目出现「对话」入口后，可重新打开同一会话并继续讨论，不会自动再次精修。绘图工具等待后台精修完成后向助手返回验证结果；具体位置建议仍由受限的内部分析步骤生成。

精修分析允许模型在 JSON 前后附带解释或代码围栏，但只接受唯一且符合严格字段及位置范围约束的方案。若格式无效，系统会在同一分析中提示模型修正一次；两次均无效时报告格式问题并保留工程。返回空调整列表表示没有可靠的可验证差异，与格式错误分开报告。

精修候选的 `layout-readback.json` 以本地设计为最终目标；补偿后的 Origin 请求值对应的诊断另存为 `requestedPositionReadback`，不用于判断本地设计是否达标。位置描述由实际请求的数值生成，Y 比例增大为向下。导出后的文字锚点和富文本重排仍可能产生偏差，位置读回不是像素级视觉验收。

## Origin 往返预览（试行）

条目图片和编辑器默认使用 Origin 的最终 PNG；本地交互图明确标注为草图。新渲染会先显示 Origin 的第二张进度图，标明“未定型”，最终图可用后再替换。进度图和最终图分别记录解码后 RGBA 像素指纹，只有结果中的 `pixelVerification.equal` 为真才说明两张导出在该次渲染中相同；传输完整性仍用文件哈希。预览携带配置哈希与渲染 ID，不匹配当前配置时显示待更新。旧条目无元数据时使用配置比较。

编辑空闲 400 ms 后请求 900 px 快速预览：后台只保留同一条目的最新待运行请求，过期执行结果丢弃；按数据哈希、配置、字体、像素宽度和管线版本缓存最近 20 项，缓存仅在当前运行会话有效。快速图使用独立的 Origin 渲染流程，标明未验等，不能代替 1800 px 最终图；最终工程依旧通过完整导出及读回。最终 SVG 使用本机字体估算轴标题、刻度标签的包围盒，发现重叠或裁切时阻止保存；字体或定位方式不支持时显示“未验证”，不能把未检出当作无重叠的证明。

已完成的 Origin 图在普通视图中可叠加图形控制点；控制点位置是近似映射，拖动时只移动控制点和草图，不平移真实位图或承诺 1 px 误差。松手后安排新一轮快速图。原始像素模式不叠加控制点。

实验性固定页面可通过进程环境变量 `IBM_PLOT_FIXED_PAGE_MARGIN=true` 显式启用（默认关闭；设为 `false` 使用原布局）。固定页面导出后的像素不一致、位置读回未通过、文字碰撞或无法检查时，自动重新运行原布局流程，并记录回退原因；固定页面不符合验收的进度图仍标为未定型。三个历史配置的独立重绘出现文字重叠或裁切，不能以速度提高为由切换默认。轴标题校准在测试图上未通过线性拟合，仍不使用全局标定常数或自动精修轴标题。屏幕截图受缩放与设备像素比影响，不以普通屏幕截图声称逐像素相同。`scripts/migration/verify-origin-repeat.mjs` 可以运行三次原生渲染与计时；单个样本通过不能证明所有图型、字体及数据均具有确定性。

Origin 导入会使用派生 CSV 中唯一的临时列名绑定曲线，再恢复用户的列名作为工作表标签和图例。这样即使用户列名是 `A`、`B` 等 Origin 工作表短列名，也不会把另一列误作数据系列；原始数据和规范化输入不被修改。
