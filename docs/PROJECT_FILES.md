# iBM Lab 项目文件

项目以 `.ibmproject` 为入口，其所在目录就是项目工作区。新建时输入项目名称，选择独立的项目文件夹和文件名；打开时选择工程文件。最近项目列表仅保存本机入口，业务记录随工程文件保存。

```text
聚合物研究/
  聚合物研究.ibmproject       项目元数据、核心记忆版本及业务记录
  聚合物研究.ibmproject.bak   上一次成功保存的备份
  项目记忆.md
  literature/                原文、附件、来源材料与文献产物
  characterization/          表征材料（具体子目录由现有流程管理）
  资料/外部导入/              从项目目录外登记的已有材料副本
  草稿/项目申报.md
  草稿/论文润色.md
  对话/会话编号.zip           会话日志及引用附件的自动归档
```

各业务目录按需创建。普通文件也可直接放入项目文件夹，由科研助手在该目录工作。

工程文件使用带格式和版本号的 JSON。记录覆盖文献检索、精读、PPT、核心记忆版本、合成路线和证据、关联化学实体与性质、实验计划、核磁、绘图及表征任务；只包含本项目与它引用的共享化学记录。文件引用使用相对于项目根目录的标记，不绑定某台机器的盘符。旧课题首次进入工作区时原位生成工程文件，不移动原始资料。

移动或备份时复制**整个项目文件夹**。在另一位置打开后，项目路径按工程文件所在位置恢复。切换到同一项目的其他副本后，后续写入只作用于当前打开的副本；运行中的任务结束前拒绝切换。应用全局设置、模型凭据、机构浏览器登录状态不写入工程文件。

研究业务记录与写作草稿自动保存。工程文件通过同目录临时文件和原子替换写入，并保留上一版 `.bak`。外部修改、删除、格式不正确或保存冲突会报错，避免静默覆盖。损坏时可保留原件，将备份复制为 `.ibmproject` 后打开。

原生对话列表由宿主管理，工作区与会话绑定属于本机信息。原路径不变时复用本机对话；更换路径或电脑后创建本机工作区和对话，历史记录及引用附件保留在项目的 `对话/*.zip` 中，可解压查看或交给助手读取。当前没有把 ZIP 归档重新导入为原生可续写会话的功能。只有部署了宿主会话导出服务时才生成该归档。

当前版本通过应用内“打开项目…”选择文件。Windows 双击 `.ibmproject` 的系统文件关联留待正式安装包接入；本轮使用开发版验证，无需生成安装包。
