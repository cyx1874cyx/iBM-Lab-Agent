# 图片条目与基础编辑验收

日期：2026-11-02。应用：iBM Lab。

实现：现有绘图工作区新增图片条目，不伪装成 Origin 工程。导入 PNG/JPEG/WebP/TIFF/BMP/GIF，支持多文件导入、图片缩略图、原始文件下载、PNG 导出和独立编辑器。编辑器支持裁剪框及四角、像素坐标、90° 旋转、翻转、撤销/重做与恢复原图。图片编辑不调用 Origin 或 AI。保存绑定完整编辑配置和产物，原始文件保留。

证据：

- `tests/python/test_plot_images.py`：对实际 PNG 逐像素验证裁剪后 4 个旋转方向 × 4 种翻转组合、透明度、六种格式、GIF 多帧提示、EXIF 方向、无效和不足一像素的裁剪、完整分辨率与缩略图分离。
- `tests/integration/plot-images.test.mjs`：使用实际运行服务和随包 Python/Pillow，导入 PNG/JPEG/TIFF/WebP，保存后检查 PNG 尺寸与像素，检查原始字节、下载解析、失败不替换上次版本、旧修订拒绝、课题隔离、服务重启后配置与导出字节不变。配置测试 Python 路径，包装运行入口以注入一次失败，并断言不使用 Origin 操作；其余执行走真实运行服务及子进程。
- `tests/browser/plot-images.test.mjs`：真实文件拖入、PNG/TIFF 多选导入、真实 canvas 像素、裁剪框移动、撤销/重做、屏幕方向翻转、无后端调用的即时编辑、失败重试、保存重开与取消下载。使用实际前端 Remote 描述符限制测试调用。
- 已目视检查浏览器截图 `H:/107-iBM-Agent/iBM-Agent/work/plot-image-editor-preview.png`。修正按视口估算高度导致裁剪框顶底被遮挡的问题，改为按实际图片区域尺寸适配。

支持边界：图片是普通图像，不能像 Origin 工程那样选择其中的坐标轴或数据系列。多帧文件仅处理第一帧，原始多帧文件完整保留。编辑结果统一导出 PNG；此轮未扩展跨条目多图拼版。
