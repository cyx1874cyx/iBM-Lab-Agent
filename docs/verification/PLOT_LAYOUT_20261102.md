日期：2026-11-02。应用：iBM Lab。

## 行为

「多面板排版」建立独立版面，从所有已经成图的图片条目多选来源，不再限制图型及数据系列数量。当前全部导入图片格式、七类 Origin 图和已有组合版面均可选。来源以完整 PNG、预览及可用 PDF 快照固化，排版使用毫米坐标。

完成：自由拖动/多选/框选/缩放、位置尺寸、锁定和固定、页面预设与自定义尺寸、透明背景、六向对齐/对齐参照、等距/间距/等宽等高、网格、自由及约束编组、组内尺寸变化重排、参考线/标尺/吸附、裁剪/90°旋转/翻转/透明度、序号、文字/箭头/矩形/比例尺、撤销重做、保存重开及历史原图恢复。导出 PNG/PDF/TIFF，可选 150/300/600 dpi；带未保存修改时先保存再导出，失败不下载旧版本。
