# 文献阅读 PPT 模板：静态元素丢失的根因分析与改造方案

> 对象：用户提供的《文献阅读PPT模板.pptx》（378,712 B，6 页，11 个版式）。
> 方法：解包读取 `ppt/slides/*.xml`、`ppt/slideLayouts/*.xml`、`ppt/slideMasters/*.xml`、
> `ppt/theme/theme1.xml` 与 `ppt/media/*`，并对照本仓库当前的
> `src/pptx-parse.js` → `lib/ppt-templates.js` → `scripts/pptx/build_from_template.py`
> 构建链。以下坐标均为实测值（EMU，1 英寸 = 914400）。

## 1. 模板实物勘测

### 1.1 页与版式

| 页 | 版式 | 角色（据文本推断） |
|---|---|---|
| slide1 | slideLayout1 | 标题页 |
| slide2 | slideLayout1 | 摘要 Abstract |

**6 页全部挂在同一个版式 slideLayout1 上**，而该版式里只有 4 个标准占位符

`<p:bgRef idx="1001">` + `schemeClr bg1`（纯白），也没有图片。

### 1.4 字体与字号实测

| 位置 | 字号 | `a:latin` | `a:ea` |
|---|---|---|---|
| 标题页第 1 行 | 66pt | 微软雅黑 | **未设** |
| 标题页第 2 行 | 36pt | 微软雅黑 | **未设** |
| 标题页"文献汇报一" | 32pt | 微软雅黑 | **未设** |
| 标题页论文题目 | 26pt | Arial | **未设** |
| 标题页讲解人 | 20pt | Arial | **未设** |
| 页标题（摘要/方法/总结） | 24pt | Arial | **未设** |
| 正文框 | 20pt | Arial | **未设** |
| 主题字体 | — | 等线 Light / 等线 | 空 |

两个要点：

1. **模板的最小字号就是 20pt**，与需求「20 号以上」一致，不需要额外放大约束。
2. **全文没有任何一处设置 `a:ea`（东亚字体）**；中文靠 `a:latin=微软雅黑` 生效，
   而正文框写的是 `a:latin=Arial`，中文实际靠 PowerPoint 的字体回退渲染。
   要做到「中文一定微软雅黑、英文一定 Arial」，写入时必须**同时**设置
   `a:latin=Arial`、`a:ea=微软雅黑`、`a:cs=Arial`。

## 2. 根因

### 2.1 主因（一句话）

`build_from_template.py:275` 用
`prs.slides.add_slide(prs.slide_layouts[...])` **新建**一页并套版式。新版式只带
版式与母版的内容，**模板页上的页级对象一个都不会继承**——底图、蓝线、logo、页标题、
正文框全部丢失。

这条路径对"静态元素挂在版式/母版上"的模板是对的；对本模板（静态元素挂在页上）则
必然丢。也就是说这不是偶发 bug，而是**构建模型与模板结构不匹配**。

### 2.2 四个次级原因（同样会造成肉眼可见的偏差）

1. **只认占位符**：构建器把内容写进 `slide.shapes.title` 与 `body/subtitle` 占位符；
   而本模板的正文、页标题都是普通 `TextBox`，**没有一个是占位符**。
   结果是"既没有继承静态层，也没有可以写入的目标"，只能再 `add_textbox` 造新框——
   位置、字号、行距全按代码默认，与模板无关。
2. **图片自算位置**：`place_picture()` 按安全边距与比例自己算位置并居中，
   **不复用模板图框的坐标**。所以即使把图插进去了，也不会落在老师排好的
   (274320, 960120) 8229600×5394960 这类位置上。
3. **段落被写成项目符号**：`plan.slides[].bullets` 逐条写成一个段落，
   与需求「不分点、1–2 个自然段」相反。
4. **解析阶段不记录页级静态形状**：`src/pptx-parse.js` 提取的是版式/占位符/主题，
   没有"这一页有哪些静态形状、叫什么、在哪、用哪张图"的清单；
   于是即便想在构建期重建，也没有数据可用。

## 3. 现有解析流程在这套模板上的表现

```
pptx ──parse──▶ parse.json ──plan──▶ plan.json ──build──▶ deck.pptx ──conformance──▶ 报告
       ↑ 记录版式/占位符/主题        ↑ 角色→版式映射、bullets、image   ↑ 按版式新建页
```

| 阶段 | 现状 | 在本模板上的后果 |
|---|---|---|
| parse | 提取 slide 列表、layout 名/索引、占位符、主题字体主色 | 页级静态形状（底图/线/logo/文本框）**不入清单** |
| plan | 角色（cover/abstract/methods/…）→ 版式；bullets；image | 与模板真实的"摘要页/方法页/结果页/总结页"结构无关，6 页共用 1 个版式时无法区分 |
| build | `add_slide(layout)` + 占位符写文字 + `add_picture` 自算位置 | **静态层全丢**；无占位符可写 → 新造文本框；图不在模板位置 |
| conformance | 比对主题字体/主色、必需页、页数上限、备注 | 因为成品是"重新生成的白底页 + 默认字体"，**主题字体本来就不一致却检查不出来**（模板主题是等线，页级覆盖是雅黑/Arial，检查只看主题） |

> 顺带说明：`pptx-conformance` 只比对**主题**字体/主色，而本模板的雅黑/Arial 是
> **页级覆盖**，所以这项检查对"是否保持了模板字体"实际上是盲的。改造时应把
> "页级 run 字体是否 = 模板同名形状的字体"纳入检查。

## 4. 你的四条需求 → 落地方案

| 你的需求 | 实现方式 |
|---|---|
| 只有 Agent 填 4 处内容，其余不许动 | **克隆模板页**而不是新建页：静态层原封不动，只改指定形状的文字/图片 |
| 中文微软雅黑 / 英文 Arial / ≥20pt | 写入时统一设 `latin=Arial` + `ea=微软雅黑` + `cs=Arial`，字号取模板该形状原值（20/24pt），**不放大不缩小** |
| 图释与摘要不分点、1–2 个自然段、填满剩余区域 | 正文写成**连续段落**（不写 `buChar`/`buAutoNum`），关闭自动项目符号；文本框设 `word_wrap=true`，字号从 20pt 起，超出则该框内自动缩排（或按字符数选 20/18pt 下限保护——低于 20pt 时改为截断并告警） |
| 标题页底图位置大小不变；其余页"上边线以上"全部不变 | 克隆页天然满足；**上边线以下**只替换 `Picture 6` 的图片与 `TextBox 7/8` 的文字，蓝线 `Rectangle 3`、logo `Picture 4`、页标题 `TextBox 5` 一律不动 |

### 4.2 构建方式：克隆页（推荐）而不是重建静态层

| 方案 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| **A. 克隆模板页**（推荐） | 用 python-pptx 载入 `source.pptx`，对计划中的每一页 `deepcopy` 模板对应页的 `spTree`（或整页 XML）作为新页，再按槽位名替换文字/图片 | 静态层 100% 保留（含复杂形状、主题引用、图片关系）；不依赖对坐标的重写 | 需要处理关系（`r:embed`）与图片部件的复制；页数超过样板页数时要决定复用哪一页 |
| B. 重建静态层 | 解析期记录静态形状，构建期按原坐标把线/logo/底图重新画到新页 | 页数任意 | 要重写坐标与形状属性，遇到组合形状/主题填充/阴影就会走样；图片关系也要自己缝 |
| C. 只做占位符 | 把模板改成"带占位符的标准版式" | 实现最省 | **要求老师改模板**，且与你"位置大小始终不变"的强约束相冲突 |

推荐 **A + 页数回退规则**：

- 计划里的每页声明它要用模板第几页当样板（`templateSlide`）；
- 样板页不够用时，按角色复用最近的同角色样板（例如第 3 个方法图 → 复用 slide3 或
  slide4，取决于图文左右）；
- 只在样板页的**槽位形状**上写内容，列表之外的形状一律不动。

### 4.3 Agent 的任务边界（与你列的四件事一一对应）

| Agent 产出 | 写入的槽位 |
|---|---|
| 1. 中文题目 / 英文题目 / 日期 | slide1 `TextBox 6`（中英各一段）、`TextBox 9` |
| 2. 摘要截图 + 摘要中文翻译（一整段） | slide2 `Picture 6` 的图片、`TextBox 7` 的文字 |

## 6. 风险

1. **图片与校徽的再分发**：`image1.png`（`ustc_seal.png`）与 `image2.png` 会随生成的
   deck 复制；若模板进入仓库作为 fixture，需要确认可再分发。
2. **形状名不是稳定契约**：老师在 PowerPoint 里重命名/重排形状会让"按名定位"失效；
   因此槽位匹配要用**名称优先 + 几何校验**，不一致时报明确错误而不是静默写错位置。
3. **字体可用性**：微软雅黑只在 Windows 存在；Linux/macOS 预览（LibreOffice）会回退，
   这是预览差异，不影响 Windows 端成品；需要在预览说明里写清。
4. **"填满剩余区域"与 20pt 下限会冲突**：文字多到 20pt 装不下时只能截断或缩排。
   建议策略：先按 20pt 排版，溢出时优先允许到 18pt 并在符合性报告里给 warning，
   仍溢出则截断并告警——**不静默缩到不可读**。
5. **`p:bg` 只在母版上**，所以"底图"其实只有标题页那一张校徽；如果还有其他页想加底图，
   必须明确是"加到母版"还是"逐页加"，两者的改造方式不同。
