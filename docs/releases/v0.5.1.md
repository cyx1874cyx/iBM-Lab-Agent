# v0.5.1 发布说明

发布日期：2026-09-17

## 主要更新

- 核磁分析和科研绘图登记条目新增删除按钮。删除登记前需要人工确认，任务与关联索引同步移除，课题目录中的 FID、MOL、Mnova、Word、Origin 等原始数据和归档产物保持不变。
- 修复预设 iBM-Agent 对话模式无法选择的问题。
- 文献下载队列支持停止失败或长时间等待的任务，Agent 在失败后会询问是否终止。
- 增加 Wiley Online Library 的 iWAN 自动下载规则：等待人机验证，正文经 PDF 预览保存；SI 展开 Supporting Information 后选择 Filename 文件并从预览页捕获。

## 验证

发布包通过统一 Windows 发布流水线构建，包括客户端一致性、Node 单元与集成测试、回归、预设导出、ESLint、浏览器 Ketcher 验收、桌面运行时验证、Web 冒烟、Tauri/NSIS 构建和安装包复验。
