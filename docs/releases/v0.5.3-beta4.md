# v0.5.3-beta4 发布说明

发布日期：2026-09-22

## 主要更新

- **软件内浏览器并入 DSH 自带右侧栏。** WebVPN 不再是桌面端自己按三分之一宽度分出来的
  一栏，而是 DSH 右侧栏里与「文件」「文档预览」并列的一类 tab（「文献浏览器」）。让位、
  收起、拆分、浮动与全屏交给 DSH 的停靠面；桌面端只负责把原生子 WebView 贴到该 tab 的
  正文区域上，主 WebView 始终保持全宽。
- **浏览器进入右侧栏「+」的类型列表**，初始页为中国科大 WebVPN 门户；载体已存在时不重新
  导航，登录态与当前页面都保留。
- **课题空间页面成为右侧栏的一类资源 tab：每个课题一个标签页。** 点对话头部右上角的课题
  徽章即在侧栏打开该课题的空间页面（每课题一标签，互不覆盖）。右侧栏的页面 tab 身份只由
  kind 决定，因此课题走**资源**语义（`dsh-resource://lab-project/<projectId>`）。
- **tab 里放的是课题空间页面本身**，复用全屏面板里的 `Project`，只套一层嵌入样式把全屏
  布局收敛成单列；三个业务选项（文献资料 / 研究设计 / 表征分析）保持**一排三个**。
- **WebVPN / iWAN 状态移到桌面壳顶栏**（「检查更新」左边），不再出现在课题页里；顶栏的
  WebVPN 指示器仍由 Harness 侧接手执行，保证先开右侧栏 tab 再打开门户。
- **移除废案「数据库状态」**面板及其全部客户端代码与样式，删掉课题页右上角的
  「开始科研 Agent 对话」按钮（起会话改由具体任务按钮按需触发）。
- **点击文献检索条目不再跳转到对应对话**；该行不再是可点区域，只有「检索 / .ris / 删除」
  按钮生效。
- v0.5.2-rc.1 验证过的**首次启动引导、环境诊断、软件封装 Python 强制执行与
  PowerShell 5.1/7.x 兼容性**一并并入。

## 已知限制

- 原生子 WebView 始终绘制在 Web 内容之上：DSH 的浮层若覆盖到 tab 正文区域会被浏览器
  画面遮住。拖动右侧栏宽度时子 WebView 有约一帧滞后（原生覆盖层方案的固有代价）。
- 文献浏览器 tab 仅桌面壳内可用；纯网页部署会显示说明文案并回落到原生路径。
- 贡献 guide 条目后 guide 条目数由 1 变 2，**右侧栏首次展开的默认页由「文件」变为指南页**。
  这是「+ 里能选浏览器」的固有语义，无法两全。
- 课题 tab 是「全屏页按单列塞进窄列」：`项目记忆.md` 编辑器、合成路线工作台这类宽内容
  尚未逐一打磨，可能需要横向滚动。三个业务选项挤在一排三个里也偏窄。
- 课题列表侧还没有直达入口，只能从「已绑定课题」的徽章进入。

## 仍需真机人工验收

本机没有 cargo/rustc，Rust 侧的右侧栏改造未经本地编译（由发布流水线在 Windows/MSVC 上
编译通过），且以下交互只能在 Windows 实机确认：

1. **桌面壳顶栏**（「检查更新」左边）出现 WebVPN 与 iWAN 两个指示器；红/黄/绿点与文案
   跟随真实状态变化（登录后变绿、iWAN 全局可用后变绿）。
2. 点顶栏 WebVPN 指示器 → 右侧栏出现「文献浏览器」tab 并打开中科大 WebVPN 门户；
   **不得**出现主界面被收窄的旧分栏行为。
3. 右侧栏「+」→ 类型列表里能看到「文献浏览器」，点它同样自动打开门户。
4. 切到其他 tab、收起右侧栏、关闭 tab 时，子 WebView 立即消失（不得继续浮在对话区上）。
5. 拖动右侧栏宽度与切换全屏时子 WebView 跟随，不留白边、不越界。
6. 登录后实际点击出版社 PDF 下载，归档链路仍正常；未获取正文/SI 的条目点下去会打开浏览器
   到门户，已有任务在处理时会把浏览器带回正在下载的页面。
7. 点对话头部右上角的**课题徽章** → 右侧栏出现以课题名为标题的标签页，正文是完整的课题
   空间页面；**同时打开两个课题** → 两个独立 tab，重复点同一课题只聚焦已有 tab。
8. 课题页里：三个业务选项**在一排三个**里；**不再有**「数据库状态」那一行，也**不再有**
   「开始科研 Agent 对话」按钮。
9. 点击文献检索条目**不再跳转对话**；条目右侧的「检索 / .ris / 删除」仍正常。
10. 侧栏窄列里的横向溢出检查：文献列表、模板管理、合成路线工作台。
