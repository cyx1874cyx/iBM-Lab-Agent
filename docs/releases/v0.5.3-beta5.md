# v0.5.3-beta5 发布说明

发布日期：2026-09-22

## 主要更新

- **修复：iWAN 可用时不再强制先过 WebVPN。** 之前「文献浏览器」tab 首次可见时总会把载体
  开到 WebVPN 门户，即使用户走的是出版社页面直连；捕获正在布防时这条初始页逻辑还会晚一步
  把出版社页面盖掉。现在：布防窗口内不抢导航，iWAN 全部路由可用时不开门户，载体已存在时
  一律不重新导航。
- **修复：出版社 PDF 预览页看不到预览器自己的工具栏按钮（只能右键另存）。** 注入的浏览器
  工具栏是 `position:fixed` 覆盖层且没有把页面推下去，预览器工具栏正好落在被盖住的 76px
  里。现在对 `html` 施加位移把页面整体推到工具栏之下（对 `html` 的 transform 会让它成为
  `position:fixed` 后代的包含块，PDF 预览器那类整屏容器因此也会一起下移），工具栏自身
  等量反向抵消。
- **新增：捕获小球。** 手动/自动文献捕获期间，浏览器页面右下角出现一个浮标，显示当前
  阶段（等待下载入口 / 正在下载 / 正在归档，下载中带已接收字节），点击即终止本次捕获——
  与状态条上的「终止下载」走同一个出口（取消任务、销毁以免网络传输继续、保留登录 profile）。
- 沿用上一版：软件内浏览器并入 DSH 自带右侧栏；课题空间页面作为资源 tab 每课题一标签；
  WebVPN / iWAN 指示器在桌面壳顶栏；「数据库状态」与独立的「开始科研 Agent 对话」按钮已移除；
  点击文献检索条目不再跳转对话；三个业务选项一排三个。
- v0.5.2-rc.1 验证过的**首次启动引导、环境诊断、软件封装 Python 强制执行与
  PowerShell 5.1/7.x 兼容性**一并并入。

## 已知限制

- **页面位移是全局 CSS 干预**：对 `html` 施加 transform 会影响所有 `position:fixed` 页面的
  定位基准。绝大多数页面因此「整体下移」正是期望效果，但个别站点可能布局异常；这是为了
  让出版商的 PDF 预览器工具栏可点而必须付的代价。若真机上出现站点异常，优先反馈具体域名。
- 捕获小球的出现/消失由壳按 5 秒节奏推进（捕获开始/终止时会立即推一次），因此小球状态
  最多滞后约 5 秒；下载中的字节数也是这样刷新的。
- 原生子 WebView 始终绘制在 Web 内容之上：DSH 的浮层若覆盖到 tab 正文区域会被浏览器画面
  遮住。拖动右侧栏宽度时子 WebView 有约一帧滞后。
- 文献浏览器 tab 仅桌面壳内可用；右侧栏首次展开的默认页因 guide 条目增加而由「文件」变成
  指南页。
- 课题 tab 是「全屏页按单列塞进窄列」，宽内容（`项目记忆.md` 编辑器、合成路线工作台）
  尚未逐一打磨。

## 仍需真机人工验收

1. **iWAN 可用时点「尚未获取正文/SI」** → 浏览器直接开出版社页面，**不得**先跳到
   WebVPN 门户、更不得出现门户把出版社页面盖掉。
2. **未获取文献且 iWAN 不可用时** → 浏览器仍应先开 WebVPN 门户（这条不能被上一条改坏）。
3. **出版社 PDF 预览页** → 预览器自己的工具栏（下载 / 保存）可见且可点，不再只能右键另存；
   同时确认顶部的浏览器工具栏（标签页 + 地址栏）仍在原位、没有跟着页面一起下移。
4. 普通网页（如 WebVPN 门户、出版社 landing page）整体下移后**没有出现大片空白或错位**；
   如有站点异常请记录域名。
5. **捕获小球**：发起手动或自动捕获后，浏览器右下角出现浮标；状态随阶段变化
   （等待入口 → 下载中带字节 → 归档中）；点它 → 捕获终止、浏览器关闭、任务不再占队列。
6. 捕获结束后小球消失（5 秒内）；终止后再发起一次捕获，小球应重新出现。
7. 上一版的既有项：顶栏 WebVPN/iWAN 指示器、课题徽章开侧栏标签页、双课题两个 tab、
   检索条目不跳转、三个业务选项一排三个。
