# v0.5.3-beta8 发布说明

发布日期：2026-09-23

## 主要更新

- **修复：出版社页面的人机验证框一直上下跳、渲染不出来（ScienceDirect + iWAN 实测；同一 URL
  在外部 Edge 正常）。** beta6 为了让出版社 PDF 预览器的「保存/下载」按钮不被软件内浏览器的
  76px 工具栏盖住，对**每一个页面**在 DOMContentLoaded 时无条件注入
  `html{transform:translateY(76px);height:calc(100% - 76px);overflow:auto}`。`transform`
  会让 `html` 成为所有 `position:fixed` 后代的包含块，同时 html 高度被改小；Cloudflare
  Turnstile 一类**按视口做垂直居中/尺寸自适应**的验证组件，测量到的可用高度与被重定位后的
  实际位置每帧互相纠正，于是验证框在应出现的位置上下抖动、始终渲染不完（地址栏与页面标题
  都是正常文章页，所以看不出是布局问题）。现在：默认**不再**位移任何页面，只由桌面壳在确认
  进入 PDF 预览器后调用 `window.__ibmWebVpnSetPageOffset(true)` 打开——触发点是出版社自动化
  的 `pdf-manual` 信号，以及直接落到 `.pdf` 的内置查看器。
- **新增：位移看门狗。** 开启位移后 2.5s 检查页面是否仍无可见内容（无文字、无图片/内嵌
  对象、无可视子元素）；判定异常就自动撤销位移，并经 `ibm-webvpn://offset-reverted/`
  记一条浏览器事件。即使预览器识别判断错了，也不会把页面变成打不开的样子。
- 沿用 v0.5.3-beta7：精读模板导入按 Markdown 标题解析成真实章节骨架、精读生成契约落盘由
  Agent 用 `read` 读取、审计按真实章节与篇幅校验；PPT 以导入模板 `source.pptx` 为起点构建并
  做模板符合性检查（页面尺寸、主题字体与主色）。
- 沿用 v0.5.3-beta6：iWAN 可用时不强制先过 WebVPN、出版社 PDF 预览页工具栏可点、
  捕获小球（窗口左下角、不随页面滚动）；软件内浏览器并入 DSH 自带右侧栏、课题空间页面
  作为资源 tab 每课题一标签。
- 沿用 v0.5.2-rc.1 验证过的**首次启动引导、环境诊断、软件封装 Python 强制执行与
  PowerShell 5.1/7.x 兼容性**。

## 已知限制

- **页面位移只在识别出 PDF 预览器时开启**：如果某家出版社的预览器没有被自动化识别为
  `pdf-manual`，其自带工具栏可能仍被我们的工具栏盖住，此时仍可右键另存，或手动在地址栏
  再次打开 PDF 预览页；这是为了杜绝验证组件被位移打架而接受的取舍。看门狗记录的事件可在
  浏览器事件列表里看到。
- 直接落到 `.pdf` 时依赖 WebView2 内置查看器里也能执行注入脚本；若该文档不执行脚本，
  位移开关是空操作（不会报错），行为退回 beta6 之前。
- 沿用 beta7：PPT 按模板构建依赖 `python-pptx`（桌面版由软件封装 Python 提供），源码环境
  缺少时构建工具以退出码 2 + 明确 JSON 错误失败，不产出伪结果。
- 课题 tab 是「全屏页按单列塞进窄列」，宽内容（`项目记忆.md` 编辑器、合成路线工作台）
  尚未逐一打磨。
