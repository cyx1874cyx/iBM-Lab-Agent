## 2. 本版本内容（WebVPN 软件内浏览器）

- 默认 USTC WebVPN 门户，旧空配置自动迁移；
- 独立、持久化、单例 WebView2 登录窗口；无 Tauri IPC capability，日志脱敏，禁止读取 profile 内容；
- WRD AES-128-CFB 目标 host 转发 URL（`aes` / `cfb-mode` 依赖新增），导航白名单仅门户与 `id.ustc.edu.cn`；
- 出版社页面 PDF/SI 下载回调 → 受限临时文件 → loopback 一次性令牌上传；
- 失败、超时、取消、Edge 回退时清理 pending task；
- 客户端入口：打开、确认登录、状态刷新、清除登录状态；
- WebVPN 路线不要求安装浏览器扩展，与既有 Edge 扩展捕获、OA 自动下载并行可用。
