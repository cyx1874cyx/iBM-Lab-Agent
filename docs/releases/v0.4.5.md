# v0.4.5 发布说明

日期：2026-09-15

## 版本位点

工程、桌面端、Tauri、运行时登记、锁文件与发布清单统一为 `0.4.5`。

## 本轮变更

- 文献下载新增并完善 iWAN 模式；iWAN 可用时出版社页面、正文和 SI 均采用直连访问。
- 优化浏览器捕获下载队列，改为单任务顺序执行，展示排队位置并避免桌面壳繁忙时重复领取任务。
- 完善 Nature、Science、Elsevier、SpringerLink、ACS、RSC 与 IEEE 的正文及补充材料自动化流程。
- 恢复 DSH 更新后首页、侧栏和课题页的 iBM 品牌图标与文案。
- 移除新版 DSH 已内置的重复文件上传入口。
- 修复 WebVPN/iWAN 状态提示、侧栏控件、课题条目操作以及黑白主题下图标可见性。

## 发布目标

- Windows x64 NSIS 安装包：`iBM Lab Agent_0.4.5_x64-setup.exe`
- DSH：`0.1.5-rc.1`
- Node.js：`24.16.0`
- Python：`3.11`
