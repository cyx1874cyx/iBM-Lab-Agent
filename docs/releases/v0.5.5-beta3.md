# v0.5.5-beta3 发布说明

发布日期：2026-09-25

## 主要更新

**取消 PPT 生成流程的向后兼容层 —— 只保留一条标准路径（编译 → 构建）。**

起因是排查"向后兼容是否影响效果"时确认：旧路径会**绕过编译期的四项门禁**（必填槽、容量、
按图片真实比例选版式、提示文字绑定），而它正是 0.5.4 试用复盘里"溢出磨 10 轮"的成因。
留两套流程的后果是"成品效果取决于 Agent 恰好走了哪条路"，这不可接受。

### 删掉的东西

| # | 位置 | 旧行为 | 新行为 |
|---|---|---|---|
| 1 | `scripts/pptx/build_from_template.py` | `--plan` 手写计划入口，`item.title/subtitle/bullets/imageCaption` 按占位符**类型**填充 | **只接受 `--compiled`**；内容只来自 `texts[]`（按提示文字/idx/形状名定位）。传 `--plan` 或两者都不给都退出码 2，并给出"先编译"的可执行指引 |
| 2 | 生成契约（`lib/tasks/presentations.js`） | 模板缺 manifest 派生件时降级为 `parse.json` 旧路径，契约里写明"槽位规范不可用" | 缺 `slots.json` **直接报错**：「标准流程要求重新导入该模板（模板 id 不复用，请用新 id 导入）」 |
| 3 | `lab_ppt_build_from_template` | 参数 `planPath`（可传手写 plan） | 参数改名 **`compiledPath`**（必须是 `kind=compiled-plan`；否则明确报错） |
| 4 | `lib/pptx-plan.js` | `slide.imageCaption` → 图注槽的旧映射；compiled 里输出 `imageCaption` | 删除；图注只认 `caption` 槽 |
| 5 | 契约文档里的 plan 结构 | 同时给出槽位写法与旧字段写法，并写"旧字段仍然可用" | 只给槽位写法；进阶只保留 `texts[]`（显式定位/段落模式），并说明编译器会原样透传 |
| 6 | 符合性报告每页摘要 | `titleChars` / `bulletCount` | `slotCount` / `paragraphCount` / `textChars` |

### 影响与迁移

- **老模板**（导入时没有 pptx-cli，或导入早于 0.5.4，因而没有 `manifest/` + `slots.json` +
  `GUIDE.md` + `lint.json`）**不能再用于生成 PPT**：取生成契约时会直接报错。
  迁移方式：在该环境具备 pptx-cli 后，**用新 id 重新导入**（模板 id 不复用是既有规则）；
  `relint` 对这类模板也会明确拒绝并说明原因。
- **导入本身仍然容错**（pptx-cli 缺失时不阻断导入、不留半成品），因为开发/CI 环境可能没有
  pptx-cli —— 但导入日志会明确写出"该模板不能用于生成 PPT"，不再让它看着像可用。

### 保留的东西（并说明它们不是兼容层）

- `parse.json`：**在跑的依赖**，不是垫片 —— builder 用它做版式定位（`index_layouts` /
  `resolve_role_layout` / `pptx_layout_index` / `page.ratio` / `layoutCount`）。
- `compiled.json` 里的 `roles`、`texts[]` 显式写法：标准流程内部契约。
- 渲染助手"kit 优先、宿主 soffice 兜底"：运行时鲁棒性（不同环境有没有 kit），不是版本兼容。

### 实测

| 项 | 结果 |
|---|---|
| 标准流程端到端（真实模板 + 真实 5 页计划） | 编译 `error 0 / warning 5` → 构建 `ok=true, planKind=compiled, errors=0` |
| 传 `--plan` | 退出码 2，`--plan 旧路径已移除：请先编译 …` |
| 两者都不给 | 退出码 2，`--compiled is required（编译产物 compiled.json；不要手写 plan 直接构建）` |
| 手写 plan 走服务构建 | 抛错：`不是编译产物（缺 kind=compiled-plan）：不能直接用手写的 plan 构建` |
| 缺 slots.json 的模板取契约 | 抛错：`缺少槽位规范（slots.json）…标准流程要求重新导入` |
