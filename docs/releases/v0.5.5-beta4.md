# v0.5.5-beta4 发布说明

发布日期：2026-09-25

## 主要更新

- 科研 Agent 可对当前文献捕获任务请求页面观察、按短期元素引用点击下载入口，并查询操作结果。页面导航、任务替换或超时后旧引用失效。
- Windows 文献 WebView2 新增原生 PDF 另存为入口。只接受当前顶层 PDF，保存后仍由现有文件校验与课题归档链路确认；HTML 预览页不会被打印成“原文 PDF”。
- 文献捕获提示细分为打开页面、查找入口、已点击、人工验证、下载/保存、归档和完成/失败；完成或失败提示短暂保留。
- 新增八家常见出版社的待核验标定文件，公开页面观察与已登录 iWAN 实测结果分开记录。DSH 上游 Sidebar Browser 在本 Tauri 项目中走 iframe，文献工具继续使用原有 WebView2 会话。
