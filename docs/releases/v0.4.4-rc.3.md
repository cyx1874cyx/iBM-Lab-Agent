# v0.4.4-rc.3 预览版登记

日期：2026-09-13

## 版本位点

工程、桌面端、Tauri、运行时登记与发布清单统一为 `0.4.4-rc.3`。

## 本轮变更

- Nature 正文继续通过用户手动建立的 WebVPN 会话访问，文章页加载后自动识别并点击正文 PDF 下载入口。
- Nature SI 继续采用直连，自动识别 Supplementary/Supporting Information、Supplementary Methods、Supplemental Methods、Supplyment Methods 及常见附件链接。
- 正文识别明确排除补充材料、Methods、Source Data 等链接，避免正文与 SI 误点。
- 页面确认无 SI 时结束捕获任务并提示“未发现补充材料或补充方法”，不再无限等待。
- 出现验证码、机器人验证或安全检查时停止自动化，等待用户处理后重新发起。

## 预览范围

本轮只更新本机当前预览程序，不生成 Windows 安装包。
