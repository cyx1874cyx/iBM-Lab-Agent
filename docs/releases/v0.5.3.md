# v0.5.3 发布说明

发布日期：2026-09-22

## 主要更新

- **软件内浏览器并入 DSH 自带右侧栏。** WebVPN 不再是桌面端自己按三分之一宽度分出来的
  一栏，而是 DSH 右侧栏里与「文件」「文档预览」并列的一类 tab（「文献浏览器」）。让位、
  收起、拆分、浮动与全屏交给 DSH 的停靠面；桌面端只负责把原生子 WebView 贴到该 tab 的
  正文区域上，主 WebView 始终保持全宽。改造前 Rust 侧按 `width / 3.0` 自行分栏、客户端
  再轮询状态同步的两套逻辑随之删除。
- v0.5.2-rc.1 验证过的**首次启动引导、环境诊断、软件封装 Python 强制执行与
  PowerShell 5.1/7.x 兼容性**随本次转正。

## 已知限制

- 原生子 WebView 始终绘制在 Web 内容之上：DSH 的浮层若覆盖到 tab 正文区域会被浏览器
  画面遮住。拖动右侧栏宽度时子 WebView 有约一帧滞后（原生覆盖层方案的固有代价）。
- 该 tab 仅桌面壳内可用；纯网页部署会显示说明文案并回落到原生路径。

## 仍需真机人工验收

本机没有 cargo/rustc，Rust 侧的右侧栏改造未经本地编译（由发布流水线在 Windows/MSVC 上
编译通过），且以下交互只能在 Windows 实机确认：

1. 点「打开 WebVPN」后，WebVPN 内容嵌在「文献浏览器」tab 的正文区域内，且与自带
   「文件」tab 并列、可点击切换。
2. 切到其他 tab、收起右侧栏、关闭 tab 时，子 WebView 必须立即消失（不得继续浮在对话区上）。
3. 拖动右侧栏宽度与切换全屏时子 WebView 跟随，不留白边、不越界。
4. 登录后实际点击出版社 PDF 下载，归档链路仍正常，切换 tab 后登录态保留。
