# v0.5.0 发布说明

发布日期：2026-09-17

工程、桌面端、Tauri、运行时登记、锁文件与发布清单统一为 `0.5.0`。

## 主要更新

- 文献下载新增软件内 WebVPN 侧栏、iWAN 状态识别、出版社规则和浏览器自动化下载队列。
- Nature、Science、Elsevier、SpringerLink、ACS、RSC 与 IEEE 下载流程按正文和补充材料分别处理。
- 合成路线工作台改为单步骤全宽翻页展示，修复结构、箭头、表格宽度和审核补绘层级问题。
- 核磁工作流支持直接提交 FID/ZIP 与结构文件，由 Agent 自动建任务、预检、标峰、生成报告并归档。
- 核磁登记新增结构判断与 `High / Medium / Low` 置信度，支持完成后重新登记并保留旧版产物。
- 修复 DSH 升级后的品牌图标、科研 Agent 入口、侧栏控制、表格布局及多处白屏问题。

## 交付物

- Windows x64 NSIS 安装包：`iBM Lab Agent_0.5.0_x64-setup.exe`
- Windows 桌面程序：`ibm-lab-desktop.exe`
