# iBM Lab v0.8.0-rc.1

本地 Windows x64 候选构建，2026-10-23。软件对外名称统一为 iBM Lab。

## 本次更新

- 三栏科研工作台，支持窗口自适应、标题栏拖动和更清晰的字体。
- 使用 `.ibmproject` 打开项目空间；未加载项目时显示欢迎页。
- 文献检索与精读分栏，支持整列拖拽导入、PDF/DOCX 补充材料自动匹配、实时刷新、排序和多选。
- 核磁条目采用原始数据与结构文件双输入，提供结构预览、分析控制、报告和文件夹入口。
- 试剂管理支持清单检索；科研绘图为独立模块。
- 知识库支持连续问答、来源核对、明确指令后归档至精读文件夹，以及其他科研模块的只读查询。
- 同一文献或核磁条目复用对应对话，预览与任务按钮打开该条目绑定的对话。
- 默认定位为通用科研助手，保留既有用户配置与研究记录。

## 安装与升级

安装包：`iBM-Lab-0.8.0-rc.1-Electron-x64-Setup.exe`。

支持相同固定基座的 `0.5.8-rc.1` 和 `0.6.0-rc.1` 数据升级。首次启动刷新安装器管理的产品插件，并在用户数据目录的 `recovery/ibm-plugin-modules/` 保留被替换版本。

当前候选包为本地未签名构建；不包含开发环境的项目、对话、知识库索引或登录凭据。依赖基座保持 Electron 44.0.0、DSH NEXT 2.0.17-next、Harness 0.2.0-rc.2 和 Python 3.12.11。
