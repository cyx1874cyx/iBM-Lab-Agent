# v0.5.8 发布说明

本版是**界面简化与视觉改版**版，同时修掉三处影响可用性的问题。业务功能、数据模型与
Agent 工具面没有删减，改动集中在界面布局、信息展示、按钮样式与三处缺陷。

## 界面简化与视觉改版

- **品牌去重**：产品名只保留一处（侧栏 Logo +「iBM Agent」，删掉英文副标题
  `based on DSH`）。面板顶栏不再重复「iBM Lab Agent / Project Research Workspace」，
  桌面壳顶栏不再重复产品名；会话标题右侧的预设标识（「iBM科研 Agent」）隐去。
- **顶部工具栏统一**：文件夹、更多菜单、课题入口统一 36px 高，图标尺寸、圆角、垂直对齐
  与间距一致；课题入口为「课题图标 + 课题名称 + 下拉箭头」，淡青绿填充、名称 15.5px
  半粗体、宽度随名称调整，去掉厚重阴影与双行布局；文件夹与更多菜单为浅色背景。
  WebVPN 与连接状态合并为一个紧凑状态入口（明细与操作在下拉里）；检查更新、日志、诊断
  收进 `···` 菜单；**本地服务地址从顶栏移入「诊断」详情**。
- **课题页减少嵌套**：`文献资料 / 研究设计 / 表征分析` 改为单行下划线标签页；删除三个
  模块的外层大框（`ib-board`）与重复标题、以及分类卡片的解释性副标题；检索记录与精读
  文献直接以「分组标题 + 条目列表」铺在内容区（分组标题保留条目数量），分组与条目靠
  留白与细分隔线区分。
- **精读条目信息结构**：每条只保留 ①短引用主标题（期刊名加粗斜体、卷号/页码/年份正体）
  ②中文论文标题副标题 ③操作按钮。作者、期刊、年份、DOI 与登记时间移入「详情与元数据」；
  没有中文翻译时保留可识别的原标题，不编造译名。
- **用按钮表达完成状态**：取消「精读已完成 / PPT 已完成」常驻文字。精读未完成 →「开始
  精读」（浅色描边）；已完成 →「打开精读」（青绿填充 + 白字 + 完成图标）；PPT 未完成 →
  「制作 PPT」；已完成 →「打开 PPT」（蓝色填充 + 白字 + 完成图标）；请求进行中显示加载
  图标。精读与 PPT 各自独立显示，完成按钮点击后直接打开对应成果。
- **次级操作**：PDF / SI 就是两个图标按钮——已归档点亮、未归档灰着，点灰的去出版社
  页面布防捕获；不写字（与改版前一致）。**所有操作都平铺在条目右侧的同一行里**：PDF/SI、
  简介、精读、PPT、删除；检索条目同样是查看文献、写综述、打开综述、导出 RIS、删除。
  改版过程中试过把这些操作收进 `···` 下拉，但在 DSH 的滚动容器里弹层会被裁切、跑到屏幕
  外，等于把「简介」「删除条目」这些原有功能藏没了，因此**不做任何弹层**：条目行用两列
  网格（左标题 / 右操作），按钮始终钉在右侧，只有真正窄到放不下（≤700px 的容器，即右侧栏
  课题 tab）才整行换到标题下面。简介按钮只写「简介」——篇幅要求是给 Agent 的约束，不是
  给人看的标签。
- **删除常驻解释文字**：两段捕获/检索说明、「左侧检索记录 · 右侧精读档案与下载」以及
  「工作规划、实验方案与合成路线」「NMR 等结构表征和审核结果」等布局解释全部移除。
- **字号与留白整体放大**：精读主标题 18px、中文副标题 16px、检索标题 17px、检索辅助
  14.5px、课题标题 22px、分组标题 17px、按钮 14px / 34px；研究设计与表征等原本 9–11px
  的密集界面同步提到 13–14px。窄宽度下标题换行、按钮移到下一行，**不通过缩小字号**解决
  空间不足。

## 缺陷修复与新增

- **阅读模板列表始终报错**：`lab/note_templates_list` 在客户端描述符里被声明成 0 参数，
  而前端一直用 `{ request: { kind } }` 调用，wire 层直接拒绝 —— 模板其实已经导入成功，
  只是列表永远显示 `client api: lab/note_templates_list expected 0 argument(s), got 1`。
  已改为声明 `request` 参数。同类漏声明一并修复：`synth_step_set_structure`、
  `synth_step_resolve_dual`（服务端有实现、前端在调用、描述符里没有），并新增
  `tests/unit/client-descriptors.test.mjs` 钉住「描述符 ↔ 调用点 ↔ Host 实现」三方一致。
- **默认模板（全局唯一）**：模板管理新增「设为默认 / 取消默认」，全局只保存一个默认模板
  行。设置后 `lab_note_templates_get` 不传 id、以及精读/综述任务未显式指定模板时都优先
  使用它；未设置才回退内置 `note-default` / `review-default`。按类别隔离：把综述模板设成
  默认后去写阅读笔记不会静默套用（否则会产出结构完全不对的笔记）。删除默认模板时自动
  清掉设置。
- **新建对话默认模式**：DSH 0.1.7 的新会话默认预设取自
  `agent-preset-registry` 行的 `config.default`（profile patch 层）或运行期
  `selectedDefault`；桌面 bootstrap 此前只写空的 `cordis.patch.yml`，因此默认一直是上游的
  `standard` —— 这就是「新建对话不是我预设的 iBM 科研 Agent」。现在两处一起修：
  1. **桌面 bootstrap 在启动 DSH 之前**用捆绑 Node 跑安装器同款
     `scripts/configure-default-preset.mjs`，把 `config.default: lab-research` 写进
     `profiles/ibm-lab/cordis.patch.yml`（幂等、保留用户其它行），所以全新安装的第一次
     启动就已经是科研 Agent 模式；
  2. 客户端启动时再用 DSH 设置页「设为默认」的同一个写入面写一次
     `selectedDefault`，覆盖老安装里已经存在的空 patch（仅在 roster 可读且 `lab-research`
     已注册时写入，避免写坏默认值）。
- **新建对话的课题选择框**：hero 行原来只有「工作目录」与模式两个 chip，看不出也选不了
  这条对话属于哪个课题。现在在 `conversation.hero.workspace` 槽位加一个课题 chip：
  列出全部课题（当前课题高亮），选中即确保该课题有专属工作区（缺则创建并绑定）后把空白
  会话切过去，`projects_by_cwd` 随即认出课题；菜单里保留「其他工作目录」，因此没有丢掉
  原生选目录的能力。空白新会话里 DSH 不渲染会话头部、课题徽章不可能出现，所以桌面壳顶栏
  另有一个常驻课题入口（由常驻桥推送当前课题）。
