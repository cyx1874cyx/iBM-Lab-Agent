# iBM Lab Agent v0.6.0-rc.1

发布日期：2026-10-09。此版本以当前 Electron 桌面版为候选发布基线，统一 iBM 科研插件及七个分域包的版本号；DSH NEXT、内核和 Electron 保持固定版本。

## 更新内容

- 桌面宠物支持自定义语录。单击头像随机显示一条，多条语录避免连续重复；在「iBM 插件设置 → 桌面宠物」按行添加、保存或清空。语录、窗口位置与显示状态在重启后保留，拖动头像不会误触语录。
- 修复同一课题的新对话发起文献获取时跳到历史对话的问题。浏览器、PDF/SI 捕获队列和归档记录传递来源对话标识，不同对话各自管理侧栏。
- 保留 PDF.js 连续分页、原文/译文双栏对照、页码/缩放/滚动同步、全文翻译与优化时的阅读体验修复。
- 精读笔记和文献 PPT 在生成阶段归档预览 PDF，重复打开不再重新转换；阅读条目、检索条目和课题页的界面改进一并发布。
- 保留出版社验证页处理、PDF 捕获、科研工具运行时和课题工作区内的 PPT 渲染修复。

## 安装与升级

本次提供 Windows x64 Electron 安装程序 `iBM-Lab-Agent-0.6.0-rc.1-Electron-x64-Setup.exe`。

从上一版 Electron `0.5.8-rc.1` 覆盖安装时，首次启动更新八个产品插件和安装器管理的归档引用，保留课题数据、用户配置、对话和宠物设置。被替换的插件及相关依赖配置保存在用户数据目录下的 `recovery/ibm-plugin-modules/`。

升级限定为相同 NEXT 提交和 Harness 内核的已声明来源版本；重复启动不重复替换插件。旧 Tauri 版本使用独立数据目录。

## 构建与校验

源码与安装包使用同一版本。发布产物包含安装程序、`SHA256SUMS-v0.6.0-rc.1.txt` 和 `release-verification-v0.6.0-rc.1.json`；GitHub 与 GitLab Release 提供对应下载入口。

验证覆盖源码单元/集成测试、客户端与版本一致性、隔离用户数据升级、打包后的宠物语录和同课题新对话的 PDF/SI 获取，以及安装程序内部 82 个归档的完整性。

源码测试共 864 项：852 项通过、12 项因环境条件跳过、0 项失败；回归套件 11/11 通过。安装包桌面验收与归档校验结果记录在随包发布的 JSON 中。

源码检查使用 `node --test "tests/unit/*.test.mjs" "tests/integration/*.test.mjs"`、`node scripts/build-client.mjs --check`、`node scripts/check-preset-exports.mjs` 和回归套件。桌面验收入口为 `scripts/migration/verify-pet-quotes.mjs` 与 `scripts/migration/verify-sidebar-session.mjs`，均支持 `--packaged`。
