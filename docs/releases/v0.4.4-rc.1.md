> 本候选版把 WebVPN 载体从「独立窗口贴靠」升级为「同窗子 WebView 真侧边栏」，
> 并修复此前「点打开 WebVPN 跳出纯白空窗」的两处根因。DSH 依赖未变更，仍为
> `0.1.5-rc.1`；DSH 兼容性结论沿用 `docs/releases/v0.4.3.md`。

> 真侧边栏形态的候选包，用于真机验收；验收通过后再决定转正版本号。

## 2. 本版本内容（WebVPN 同窗真侧边栏）

- WebVPN 载体改为 **Tauri 官方 `Window::add_child` 同窗子 WebView**，替代独立窗口贴靠；
  打开时主 WebView 自动收窄，WebVPN 占右侧 320–560 逻辑像素，收起后子 WebView 与专属
  profile 保留、登录态不丢；
- 修复「点打开 WebVPN 跳出纯白空窗」：① 建窗/操作窗口命令全部改 `async`（同步命令建窗
  在 Windows 上死锁）；② USTC 统一认证白名单补齐 `passport.ustc.edu.cn`（首跳 302 被拦成白页）；
- capability 从窗口级 `windows:["main"]` 收紧为 `webviews:["main"]`，外部 WebVPN 页面不继承 IPC；
- 捕获链路加固：新增 `Downloading` 态、新捕获替换旧 pending（修僵尸 pending 挡住重试）、
  上传失败保留 PDF 而非静默删除；
- 客户端阶段提示：捕获期间轮询会话状态，映射「加载出版社页 / 等待下载 / 归档中」并附 spinner；
- 顶栏新增 WebVPN 开关，按 `sidebarVisible` 同步按钮态。

## 2.1 文献工作流修复

- `lab_tasks_resolve_wechat_doi` 的成功返回统一经过无损 JSON 清洗，候选对象也不再写入值为
  `undefined` 的可选字段，修复 DOI 已找到却被 DSH 以 `value is not lossless JSON` 拒绝的问题；
- `TRI-611` 一类“字母代号 + 数字”查询改用标题精确 token 筛选，并视为明确找某篇论文，
  不受主题检索 OA 开关影响；普通主题检索会剔除没有任何词面相关证据的供应商噪声；
- 默认相关性排序同分时先比较年份，再比较引用数，避免刚上线论文被旧高引结果挤出；
- 课题面板的检索记录新增“删除”按钮，可在确认后清理误登记批次；
- 摘要概括工具和错误信息统一说明“2–9 个汉字”的计数口径，删除不可达校验分支。
