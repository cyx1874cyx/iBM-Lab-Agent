# v0.5.5-beta5 发布说明

发布日期：2026-09-25

## 主要更新

- 出版社验证页保持自动扫描，验证自行通过后继续查找下载入口。
- 下载点击不再立即触发内部状态导航，也不修改出版社链接的下载属性；若未产生下载，会继续尝试其他候选入口。
- 忽略会覆盖唯一文献页面的空白弹窗。前一个正文任务完成、失败或过期后清理本地占用，让队列中的 SI 接管浏览器。
- Agent 下载状态返回阶段、排队位置和下一步动作；原生 PDF 可继续使用页面保存工具。

对应行为：验证页只上报 `challenge` 而不结束任务，文案消失后回到 `searching`；点击后本地会记录
`__ibmWebVpnLocalClickAt`，在 WebView2 发出真实下载事件前不再被重绘回"正在查找"；`about:blank`
等非 HTTP(S) 新窗口一律拒绝并把阶段标为 `manual`，不覆盖唯一的文献页面；状态工具新增
`nextAction`（`wait-and-poll` / `observe-or-save-pdf` / `observe-or-click` / `ask-user` / `done`）
与 `queuePosition`。

## 出包过程中发现的编译错误

`74d637a` 引入的 `push_capture_ball(&download_app, webview)` 在 `on_download` 闭包里传的是
按值持有的 `Webview`，而该函数签名要求 `&Webview`，桌面 crate 因此无法编译（E0308）。
Node 单元测试看不到这类问题，只有 Rust 构建能看到：beta5 此前从未在 Windows 出包，所以一直没暴露。
`30269c4` 按编译器提示改为借用，**本版两份产物都从 `30269c4` 构建**，发布说明与标定文件也指向它。
