# v0.5.5-beta5 发布说明

发布日期：2026-09-25

## 主要更新

- 出版社验证页保持自动扫描，验证自行通过后继续查找下载入口。
- 下载点击不再立即触发内部状态导航，也不修改出版社链接的下载属性；若未产生下载，会继续尝试其他候选入口。
- 忽略会覆盖唯一文献页面的空白弹窗。前一个正文任务完成、失败或过期后清理本地占用，让队列中的 SI 接管浏览器。
- Agent 下载状态返回阶段、排队位置和下一步动作；原生 PDF 可继续使用页面保存工具。
