# v0.5.3-beta2 发布说明

发布日期：2026-09-22

## 主要更新

- **软件内浏览器并入 DSH 自带右侧栏。** WebVPN 不再是桌面端自己按三分之一宽度分出来的
  一栏，而是 DSH 右侧栏里与「文件」「文档预览」并列的一类 tab（「文献浏览器」）。让位、
  收起、拆分、浮动与全屏交给 DSH 的停靠面；桌面端只负责把原生子 WebView 贴到该 tab 的
  正文区域上，主 WebView 始终保持全宽。改造前 Rust 侧按 `width / 3.0` 自行分栏、客户端
  再轮询状态同步的两套逻辑随之删除。
- **浏览器进入右侧栏「+」的类型列表**，初始页为中国科大 WebVPN 门户；载体已存在时不重新
  导航，登录态与当前页面都保留。
- **课题主页面成为右侧栏的一类资源 tab：每个课题一个标签页。** 右侧栏的页面 tab 身份只由
  kind 决定（`sidebar://<kind>`），一个 kind 只能有一个页面 tab；因此课题走**资源**语义，
  地址为 `dsh-resource://lab-project/<projectId>`，contentId 每课题不同，天然一课题一标签。
  本版落地的是「通路 + 只读摘要」：正文显示课题编号、核心记忆版本、工作区、精读目标与
  阅读模板版本，并可一键打开原有全屏面板。完整面板的紧凑渲染仍待后续版本。
- **修复「点尚未获取文献打不开浏览器」**：未登记 DOI/出版社页面、以及已有下载任务在处理
  这两条路径原本只弹提示，现在都会真的打开/带回软件内浏览器。
- v0.5.2-rc.1 验证过的**首次启动引导、环境诊断、软件封装 Python 强制执行与
  PowerShell 5.1/7.x 兼容性**一并并入。

## 已知限制

- 原生子 WebView 始终绘制在 Web 内容之上：DSH 的浮层若覆盖到 tab 正文区域会被浏览器
  画面遮住。拖动右侧栏宽度时子 WebView 有约一帧滞后（原生覆盖层方案的固有代价）。
- 文献浏览器 tab 仅桌面壳内可用；纯网页部署会显示说明文案并回落到原生路径。
- 贡献 guide 条目后 guide 条目数由 1 变 2，**右侧栏首次展开的默认页由「文件」变为指南页**。
  这是「+ 里能选浏览器」的固有语义，无法两全。
- 课题 tab 的正文目前是只读摘要；编辑能力仍在全屏面板里。

## 仍需真机人工验收

本机没有 cargo/rustc，Rust 侧的右侧栏改造未经本地编译（由发布流水线在 Windows/MSVC 上
编译通过），且以下交互只能在 Windows 实机确认：

1. 点「打开 WebVPN」后，WebVPN 内容嵌在「文献浏览器」tab 的正文区域内，且与自带
   「文件」tab 并列、可点击切换。
2. 切到其他 tab、收起右侧栏、关闭 tab 时，子 WebView 必须立即消失（不得继续浮在对话区上）。
3. 拖动右侧栏宽度与切换全屏时子 WebView 跟随，不留白边、不越界。
4. 登录后实际点击出版社 PDF 下载，归档链路仍正常，切换 tab 后登录态保留。
5. 「+」→ 类型列表里能看到「文献浏览器」，点它自动打开中科大 WebVPN 门户。
6. 已登录时再走一次第 5 条，不得重新导航到门户、不得丢失当前页面。
7. 未登记 DOI/出版社页面的条目，点「尚未获取正文/SI」→ 打开浏览器到门户，而不是只弹提示。
8. 已有下载任务在处理时再点「尚未获取正文/SI」→ 浏览器被带回正在下载的页面。
9. 课题徽章旁的按钮 → 右侧栏出现以**课题名**为标题的 tab，正文显示该课题的摘要。
10. **同时打开两个课题** → 两个独立 tab，互不覆盖；重复点击同一课题只聚焦已有 tab
    （这是本版最关键的一条：页面 tab 做不到，资源 tab 才做得到）。
11. 「打开完整面板」仍能打开原有全屏课题面板。
