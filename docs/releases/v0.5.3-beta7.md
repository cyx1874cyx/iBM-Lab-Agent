# v0.5.3-beta7 发布说明

发布日期：2026-09-23

## 主要更新

- **精读模板按真实章节解析与生成。** 以前从主面板导入 `.md` 阅读笔记模板时，整篇文件被
  按行塞进「附加输出要求」，模板的章节骨架仍是内置默认的 2 节——模型每次都要自己重新推断
  结构，所以同一模板两次生成结果不一致，机器自查也覆盖不到真实章节。现在：导入时按
  Markdown 的 `#/##` 解析出**真实章节骨架**（`###` 子节、表格要求、【填写】提示一并保留，
  含「如有/可选」的节自动标为非必填），原文另存备查；新增解析/导入两个面板接口，
  「从 .md 文件导入」解析后回填可编辑的表单。
- **精读生成契约落盘，绕开工具结果裁剪。** `lab_tasks_get_reading_inputs` 不再把整篇模板
  塞进一次工具结果（preset 的 `tool-result-pruner` 会把超过 8192 字符的结果中段裁掉，这正是
  「同一模板两次要求不同」的元凶之一），而是把完整的「精读生成契约」（章节骨架 + 每节要点 +
  现有资源 + 强制顺序）写入文献条目目录并返回路径，Agent 用 `read` 读取、过长时分段读完。
- **精读自查按模板校验。** 阅读笔记审计改为按契约中的**真实必填章节**逐节核对，并解析模板
  里的篇幅要求（如 600-1000 字）作为正文下限，低于下限直接判 error。
- **PPT 改为以导入模板为起点构建。** 以前 PPT 模板虽然解析了页面比例、主题色、字体、母版与
  版式，但只把一段文字摘要交给模型，生成端仍从空白 `Presentation()` 自由拼版式——模板信息
  在生成环节等于不存在。现在：模板详情直接给出主题字体/主色与母版源文件路径；新增
  「PPT 生成契约」（源文件、`parse.json`、版式角色映射、最大页数、必选页与强制构建命令）与
  `lab_ppt_build_from_template`，由 `scripts/pptx/build_from_template.py` 打开模板
  `source.pptx`、按角色映射填充对应母版布局，输出成品与**模板符合性报告**。
- **新增模板符合性检查。** 构建脚本报告角色映射、必选页、页数上限、每页讲稿备注等；
  暂存与自查阶段再把成品的页面尺寸、主题字体与主色与模板逐项比对，不一致记为 error
  （只作提醒，不阻断人工审核）。`lab_tasks_register_presentation` 未显式指定模板时，
  默认使用课题创建时选定的 PPT 模板，不再静默回退 `nature-default`。
- 沿用 v0.5.3-beta6：iWAN 可用时不强制先过 WebVPN、出版社 PDF 预览页工具栏可点、
  捕获小球（窗口左下角、不随页面滚动）；软件内浏览器并入 DSH 自带右侧栏、课题空间页面
  作为资源 tab 每课题一标签。
- 沿用 v0.5.2-rc.1 验证过的**首次启动引导、环境诊断、软件封装 Python 强制执行与
  PowerShell 5.1/7.x 兼容性**。

## 已知限制

- **PPT 按模板构建依赖 `python-pptx`**：桌面版由软件封装 Python 提供；源码环境缺少时构建
  工具以退出码 2 + 明确 JSON 错误失败，不会静默产出伪结果。`nature-default` 是无源文件的
  虚拟模板，仍走 nature-paper2ppt 默认流程，不套用模板主题。
- **模板里的版式角色映射目前是导入时的自动建议**：自动建议按占位符特征打分，复杂模板仍需
  在「模板管理」里人工确认或调整后发布，否则符合性报告会指出角色/布局不匹配。
- 沿用 beta6 的浏览器限制：对 `html` 施加的位移是全局 CSS 干预，个别站点可能布局异常；
  捕获小球最多滞后约 5 秒；原生子 WebView 始终绘制在 Web 内容之上，拖动右侧栏宽度有约
  一帧滞后。
- 课题 tab 是「全屏页按单列塞进窄列」，宽内容（`项目记忆.md` 编辑器、合成路线工作台）
  尚未逐一打磨。

## 仍需真机人工验收

1. **模板管理导入 `.md`** → 点「从 .md 文件导入」后，表单里出现模板真实的章节（不再是默认
   两节），子节与表格要求保留；保存后在模板列表可见。
2. **精读报告按模板生成** → 对一篇文献调用精读，确认 `lab_tasks_get_reading_inputs` 返回
   `contractPath`，生成的报告章节顺序与模板一致、篇幅满足模板下限；机器自查不再报缺节。
3. **导入真实 `.pptx` 模板** → 确认版式角色映射并发布；取「PPT 生成契约」后按契约准备
   `plan.json`，用 `lab_ppt_build_from_template` 构建，确认成品沿用模板的页面比例、主题字体
   与主色（符合性报告无 error），母版布局与角色映射一致。
4. **登记 PPT** → 课题面板可预览、人工审核后可下载；登记记录里带所用模板与符合性报告。
5. 沿用 beta6 的既有项：iWAN 可用时不先跳 WebVPN 门户、出版社 PDF 预览器工具栏可点、
   捕获小球位置固定且随阶段更新、顶栏指示器与课题资源 tab 正常。
