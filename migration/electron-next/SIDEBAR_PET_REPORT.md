# 官方侧栏浏览器与科研桌面宠物

实施计划见 `SIDEBAR_PET_PLAN.md`。产品源码提交：`5b84811`、`b3c58ce`。固定 NEXT / 内核 / Electron 版本保持为 2.0.17-next / 0.2.0-rc.2 / 44.0.0。

## 已实现

- 复用官方 `browser` 标签页、地址栏、导航与 guest 租约。自有打包组合层替换 guest 管理器的入口，继承官方所有权检查；不修改固定上游 checkout 或内核。
- 文献任务自动切换到对应课题会话并打开右侧栏。恢复会话时等待侧栏完成挂载，避免重启后的打开请求丢失。
- 原有 PDF/SI 队列、观察/点击、格式与哈希校验、课题归档接入同一 guest。普通出版社新窗口请求在侧栏内导航；机构认证和 POST 弹窗保留原生处理。
- 工作区使用独立的持久浏览器会话。网页没有 Node、Host IPC、捕获令牌或应用认证访问权限。下载必须属于已经布防的捕获任务；取消会中止正在下载的文件。
- 使用现有人像 Logo 制作透明、可拖动、置顶的桌面宠物。动画、文案、进度来自真实任务状态；可信下载总量存在时才显示百分比。短暂显示完成/失败/取消通知，再返回进行中的工作。
- 微信元数据、精读、PPT、路线登记、核磁和 Origin 从实际工具执行事件及已有任务登记投影状态。最终工具结果来自内核 `tools/result`；单个工具成功只显示“当前步骤完成”。
- 设置 → iBM 插件设置 → 桌面宠物，可显示/隐藏；保存窗口位置与偏好。Host 连接断开时清除过时的活动显示。

## 使用与验收范围

完整退出旧版（包括托盘）后，同位置安装新包。首次切换到自带侧栏浏览器需重新完成机构登录；新侧栏不会自动复制此前独立科研浏览器的认证资料。此后会话可在同一课题内跨应用重启保留，机构自身的会话过期规则仍然适用。

验收使用本地合成出版社页面与文件，不代表已验证中科大当前权限、真实出版社下载、Origin/Mnova 许可或全部科研产物质量。所有新测试使用独立测试目录。

最终交付目录为 `outputs/electron-next-sidebar-pet/release-windows`。`final-windows` 是发现重启时序问题前的候选包，不作为交付。
