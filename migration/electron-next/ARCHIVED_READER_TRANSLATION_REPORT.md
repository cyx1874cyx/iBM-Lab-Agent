## 实现选择和边界

阅读复用 Mozilla PDF.js 5.4.624（Apache-2.0），资源随包安装，读取由 Host 按归档身份鉴权，并通过分块接口交给阅读组件。扫描页交由 Agent 识别翻译；文字、来源锚点、源图与映射保存到课题文献目录。

本版中文/双语是**全文段落阅读模式**，原始 PDF 模式保留出版社版式；不提供重新排版的中文 PDF 导出。BabelDOC / PDFMathTranslate-next 已调研，但本包未混装其 AGPL 引擎或独立模型依赖。Agent 使用用户现有模型配置，完整性校验不能替代科学术语和公式翻译质量审查。
