# iBM 插件设置（2026-10-05）

官方设置侧栏新增「iBM 插件设置」，通过 `settings.section` 扩展槽位注册。NEXT 与内核源码保持固定基线。

## 功能

- 模板管理复用现有组件和存储：阅读笔记、文献综述、实验计划、PPT。支持现有新建、导入、编辑、默认模板和归档等操作；各类别保留原功能范围。
- 诊断与版本展示实时服务状态、Python / Node.js / LibreOffice、MarkItDown、科研桌面状态与版本登记。
- 单项诊断失败单独展示，支持重新检查和下载 JSON 报告。报告包含运行路径和版本，不读取模型密钥文件。
- 原课题页模板入口保留；两处共用同一组件和存储。DSH 设置顶部的配置文件、DSH 诊断和终端操作继续由官方桌面适配器提供。

## 同版本覆盖安装

保持 iBM 0.5.8-rc.1 / NEXT 2.0.17-next / 内核 0.2.0-rc.2。启动时比较八个产品插件归档的 SHA-256，仅更新安装器管理的插件目录；旧插件放入数据目录的 `recovery/ibm-plugin-modules/refresh-*`。

候选归档全部校验并解压后才替换；替换失败回滚旧目录，更新记录最后原子写入。再次启动不重复替换。课题文件、数据库、认证配置、Profile 配置和原初始化标记不覆盖。不同产品版本仍需明确的迁移流程。

保留此前根包名修复和内核模块共用修复，避免再次出现设置永久加载或工具调用 `prepare` 异常。

## 验证

完整自动检查：807 项，799 通过、8 跳过、0 失败。新增同版本升级测试覆盖旧文件备份、数据保留、重复启动与损坏归档拒绝。

实际 Electron 中点击官方设置入口、iBM 栏目、四类模板；新建并归档隔离测试模板；读取运行诊断、刷新并导出 JSON。详见输出目录的验收记录。

所有运行验证使用独立测试目录，不操作用户正在运行的实例或真实认证配置。真实机构全文和科研软件验收范围沿用前期记录，不因本次设置调整扩大。

## 安装

使用 `outputs/electron-next-plugin-settings/final-windows/dist/iBM-Lab-Agent-0.5.8-rc.1-Electron-x64-Setup.exe`，在托盘退出正在运行的 Electron 版后安装到原位置。无需卸载或删除数据。此包仍是未签名迁移预览版。
