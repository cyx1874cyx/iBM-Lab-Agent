# 自带侧栏浏览器与科研桌面宠物实施计划

基线：iBM Lab Agent 0.5.8-rc.1；DSH NEXT 2.0.17-next；内核 0.2.0-rc.2。

1. 复用官方 browser 标签页、地址栏、前进后退和 webview 租约；在自有安装组合层接入下载，保持上游源码不变。浏览器按课题工作区持久隔离，不向出版社页面开放 Host 或 Electron 权限。
2. 将现有捕获队列、观察/点击、PDF/SI 校验和归档接到侧栏 guest。Agent 发起捕获时自动打开对应课题侧栏；取消、关闭、失败清理下载。只在必要的机构认证中保留网页弹窗。
3. 建立任务状态投影：文献加载、下载入口查找、下载、归档、完成；微信元数据、精读、PPT、路线登记、核磁、Origin 使用真实工具执行与任务登记状态。没有可信总量时只显示阶段，不估算百分比。
4. 复用人像 Logo，制作可拖动、置顶的透明桌面宠物；显示当前任务、阶段、可信进度和并行任务数。设置里的 iBM 插件设置新增显示/隐藏入口；保存位置与偏好。
5. 验证实际 Electron 侧栏、自动导航、PDF/SI 归档、机构会话隔离与重启保持、工具失败和取消、宠物联动；使用独立测试数据，不接触用户认证数据。
6. 构建更新安装包，验证同版本升级与课题记忆保留，交付安装包和验收记录。真实机构权限与 Origin/Mnova 的软件操作仅在实际验证后计为通过。
